3. 공통 기능

화면을 가리지 않고 전 화면에 걸리는 제작 기준입니다. 성능 · 반응형 · 접근성 · 보안 등 비기능 요건 전체는 별도 문서 「비기능 명세서」에 있으며, 여기에는 화면 제작에 직접 걸리는 것만 옮겨 둡니다.

  • 데스크톱 1440 · 태블릿 768 · 모바일 375 세 너비에서 가로 스크롤이 생기지 않습니다.
  • placeholder·option·input value 는 추출되지 않으므로 화면 문구로 쓰지 않는다 (겹친 글자·직접 그린 목록으로 대체).
  • 차트·아이콘·삽화는 전부 인라인 SVG 입니다. 비트맵은 Figma 에서 벡터로 복원되지 않습니다.
  • 모션 감소를 켠 사용자에게는 자동 넘김·전환이 돌지 않습니다.
  • 색만으로 상태를 알리지 않습니다
    - 모양이나 글자를 함께 둡니다.
  • 토스트는 화면 하단 정중앙 한 곳에서만 뜹니다.

8.8 예외 및 오류 응답 요구사항

순번상황발생 조건시스템 처리 · 화면 표시
존재하지 않는 데이터 조회요청한 식별자에 해당하는 데이터가 없습니다.서버는 404 로 응답합니다. 화면은 목록으로 돌아가는 경로와 함께 없는 대상임을 안내합니다.
비공개 데이터의 고객 서비스 접근공개 상태가 아닌 데이터를 고객 서비스 주소로 직접 요청했습니다.서버는 404 로 응답합니다. 데이터의 존재 여부를 드러내지 않습니다. 다만 메뉴는 판매 중지 안내와 함께 응답합니다.
삭제된 데이터 접근삭제 처리된 데이터를 요청했습니다.서버는 404 로 응답합니다. 삭제 이후 보관 기간 동안의 복구 요청은 관리자 경로로만 처리합니다.
필수값 누락필수 항목이 비어 있는 상태로 저장을 요청했습니다.서버는 400 과 함께 누락 항목 목록을 응답합니다. 화면은 입력값을 유지한 채 항목별로 안내합니다.
형식 오류연락처 · 날짜 등 형식이 정해진 항목의 값이 규칙에 맞지 않습니다.서버는 400 과 함께 항목별 사유를 응답합니다. 미입력과 형식 오류를 구분하여 응답합니다.
허용되지 않은 상태값정의되지 않은 상태값으로의 변경을 요청했습니다.서버는 400 으로 응답하며 상태를 변경하지 않습니다.
중복 데이터 등록이미 존재하는 값으로 등록을 요청했습니다. 관리자 계정의 이메일이 이에 해당합니다.서버는 409 로 응답합니다. 화면은 중복 항목을 지목하여 안내합니다.
권한 없는 접근인증되지 않았거나 등급이 부족한 요청입니다.미인증은 401, 등급 부족은 403 으로 구분하여 응답합니다. 인증 구현은 2단계 대상입니다.
검색 결과 없음조건에 해당하는 데이터가 없습니다.서버는 200 과 함께 빈 목록 및 총 건수 0 을 응답합니다. 오류로 처리하지 않습니다. 화면은 조건 초기화 경로를 함께 제공합니다.
외부 서비스 오류지도 SDK 가 응답하지 않거나 인증 키가 유효하지 않습니다.화면은 빈 영역 대신 대체 안내를 표시합니다. 매장 목록은 지도와 무관하게 조회 가능해야 합니다.
