## 4. 버튼 및 이벤트

| 버튼 | 눌렀을 때 | 성공 | 실패 |

| 저장 | 입력값을 검증한 뒤 저장한다 | 저장 완료를 안내하고 목록 화면으로 이동한다 | 검증에 실패한 입력 항목으로 포커스를 이동한다 |
| 취소 | 수정 내용을 반영하지 않는다 | 목록 화면으로 이동한다 | 수정 내용이 있으면 확인 안내를 표시한다 |

## 5. 사용자 시나리오

### 정상

- 등급 등록 · 수정 · 삭제 → 결과가 화면에 바로 반영된다.
- 적립률 및 기준 금액 설정 → 결과가 화면에 바로 반영된다.

### 인수 조건

- **Given** 이 화면을 열었을 때 **When** 등급 등록 · 수정 · 삭제 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 적립률 및 기준 금액 설정 **Then** 그 결과가 화면에 반영된다.

## 6. 예외처리

| 발생 조건 | 사용자 안내 | 화면 처리 |
|---|---|---|
| 사용 중인 등급은 삭제할 수 없습니다. 해당 등급의 회원을 배정할 등급이 없어집니다. | 무엇이 왜 막혔는지 그 자리에서 알린다 | 입력값과 스크롤 자리를 지킨 채 안내만 더한다 |

## 7. 검증 규칙

- 적립률은 0~100 범위입니다.
- 기준 금액이 중복되는 등급을 등록할 수 없습니다.

### 화면 정책

- 기본 정렬은 기준 금액 오름차순입니다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.

### 향후 확장

- 등급별 쿠폰 자동 발급
