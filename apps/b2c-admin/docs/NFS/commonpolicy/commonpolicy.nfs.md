# 공통 정책

> B2C Admin · 생성: `pnpm docs:build` · 원본: `tools/docs/nfs.ts`

## 목적

어느 문서에도 딱 들어맞지 않지만 모든 화면에 걸리는 것을 모은다.

## 적용 범위

모든 화면.

## 정책

- **서버가 없다.** 이 프로젝트는 프론트엔드 전용이고, 화면이 읽는 값은 공유 시드와 주소의 질의문자열뿐이다.
- 목록의 상태(검색·분류·쪽)는 전부 주소에 둔다 — 새로고침·공유·뒤로가기에서 살아남아야 한다.
- 3뎁스를 만들지 않는다. 돌아올 길이 길어진다.
- 404 · 오류 · 완료 · 실패는 **한 컴포넌트**를 모든 앱이 같이 쓴다.
- 디자인 값(색·글자·간격)은 앱이 소유하지 않는다 — 토큰 한 곳에서 온다.

## 세부 기준

| 항목 | 기준 |
|---|---|
| 데이터 출처 | 공유 시드 패키지 · 주소 질의문자열 |
| 상태 보존 | 주소(query string) |
| 최대 깊이 | 2뎁스 |
| 상태 화면 | 공유 `StatusScreen` 한 벌 |
| 디자인 값 | 공유 토큰 한 곳 |

## 예외

- 문서 화면은 빌드 시점에 저장소의 파일을 읽는다 — 서버 API 가 아니라 정적 생성 입력이다.

## 점검 항목

- [ ] 화면이 자기 시드를 따로 들지 않는다
- [ ] 조건이 주소에 남는다
- [ ] 토큰 밖의 색을 쓰지 않았다
