# 날짜와 시각

> B2C Admin · 생성: `pnpm docs:build` · 원본: `tools/docs/nfs.ts`

## 목적

같은 시각이 화면마다 다른 모양이면 같은 것인지 알 수 없다.

## 적용 범위

날짜·시각을 보여 주는 모든 자리.

## 정책

- **기준일은 서버가 아니라 화면을 그리는 쪽에서 한 번 정해 내려보낸다.** 화면이 스스로 읽으면 서버와 브라우저의 값이 어긋난다.
- 모양을 한 벌로 쓴다.
- "3일 전" 같은 상대 표기는 목록에서만 쓰고, 상세에서는 절대 시각을 함께 보여 준다.

## 세부 기준

| 자리 | 모양 |
|---|---|
| 날짜 | `YYYY-MM-DD` |
| 날짜와 시각 | `YYYY-MM-DD HH:mm` |
| 기간 | `YYYY-MM-DD ~ YYYY-MM-DD` |
| 시간대 | `Asia/Seoul` 고정 |
| 숫자 정렬 | 표에서는 자릿수가 흔들리지 않게 고정폭 숫자 |

## 예외

- 연혁처럼 연도만 뜻이 있는 자리는 `YYYY` 만 적는다.

## 점검 항목

- [ ] 날짜 모양이 화면마다 같다
- [ ] 기준일이 화면마다 다르지 않다
