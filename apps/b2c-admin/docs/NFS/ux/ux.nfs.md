# UX 공통

> B2C Admin · 생성: `pnpm docs:build` · 원본: `tools/docs/nfs.ts`

## 목적

같은 일이 화면마다 다르게 알려지면 사용자는 화면마다 새로 배워야 한다.

## 적용 범위

모든 화면.

## 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 늦게 안다.
- 알림은 화면 하단 정중앙 **토스트 한 곳**에서만 뜬다.
- 되돌릴 수 없는 일은 확인을 한 번 묻는다. 되돌릴 수 있는 일은 묻지 않는다.
- 기다리는 동안 자리를 비우지 않는다 — 뼈대를 그려 두어야 화면이 튀지 않는다.
- ESC 로 열린 것(모달·서랍)을 닫고, 열려 있는 동안 뒤 화면은 스크롤되지 않는다.

## 세부 기준

| 상황 | 알리는 방법 |
|---|---|
| 저장·삭제 성공 | 토스트 |
| 입력값 오류 | 그 입력 바로 아래 글자 |
| 되돌릴 수 없는 일 | 확인 모달 |
| 불러오는 중 | 뼈대(스켈레톤) |
| 결과 없음 | 목록 자리에 한 줄 안내 |
| 화면 전체 오류 | 오류 화면 + 돌아갈 길 |

## 예외

- 문서 화면은 읽기 전용이라 토스트·확인이 없다.

## 점검 항목

- [ ] 토스트가 두 곳에서 뜨지 않는다
- [ ] 잠긴 단추가 왜 잠겼는지 알 수 있다
- [ ] ESC 로 모달이 닫힌다
