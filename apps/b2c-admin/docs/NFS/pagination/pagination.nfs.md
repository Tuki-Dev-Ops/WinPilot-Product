# 페이징

> B2C Admin · 생성: `pnpm docs:build` · 원본: `tools/docs/nfs.ts`

## 목적

한 번에 다 보여 주면 느려지고, 조금씩 보여 주면 어디까지 봤는지 잃는다.

## 적용 범위

목록 화면.

## 정책

- 지금 몇 쪽 중 몇 쪽인지 **늘 보인다.**
- 쪽 번호는 주소에 남긴다.
- 가로로 넘기는 줄(상품 줄 등)은 스크롤바 대신 **장 표시**를 쓴다.

## 세부 기준

| 항목 | 기준 |
|---|---|
| 한 쪽 개수 | 목록마다 명세에 적는다 |
| 주소 파라미터 | `page` (1부터) |
| 범위를 벗어난 쪽 | 첫 쪽으로 본다 — 빈 화면을 보여 주지 않는다 |
| 무한 스크롤 | **현재 미사용.** 도입하면 쪽 번호와 함께 쓰지 않는다 |

## 예외

- 문서·명세 목록은 전부 보여 준다 — 수가 정해져 있고 훑어서 찾는 것이 빠르다.

## 점검 항목

- [ ] 현재 쪽이 보인다
- [ ] 주소에 쪽이 남는다
- [ ] 없는 쪽으로 가도 빈 화면이 아니다
