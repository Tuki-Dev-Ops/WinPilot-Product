# 언어

> B2C Admin · 생성: `pnpm docs:build` · 원본: `tools/docs/nfs.ts`

## 목적

언어를 늘릴 때 무엇을 옮겨야 하는지 정해 두지 않으면 화면마다 빠뜨린다.

## 적용 범위

화면에 보이는 모든 글.

## 정책

- 기본 언어는 한국어(`ko`)다.
- 화면 문구는 **템플릿이 정하지 않는다** — 공유 문구 묶음 한 곳에서 온다. 템플릿은 배치만 정한다.
- 다국어는 **현재 미사용.** 도입하면 모든 언어의 키 목록이 같아야 하고, 빠진 키는 검사에서 잡는다.

## 세부 기준

| 항목 | 기준 |
|---|---|
| 기본 언어 | 한국어 |
| 문구 출처 | 공유 패키지 한 곳 |
| 숫자·통화 | `1,234,000원` |
| 키 이름 | 언어마다 같아야 한다 |

## 예외

- 제품 이름·코드(`P-1042`)는 옮기지 않는다.

## 점검 항목

- [ ] 화면에 박아 넣은 문구가 없다
- [ ] 숫자·통화 모양이 같다
