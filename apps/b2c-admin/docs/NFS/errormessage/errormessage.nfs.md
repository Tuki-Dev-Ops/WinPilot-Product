# 오류 문구

> B2C Admin · 생성: `pnpm docs:build` · 원본: `tools/docs/nfs.ts`

## 목적

문구가 화면마다 다르면 같은 오류를 다른 문제로 읽는다.

## 적용 범위

모든 안내·오류 문구.

## 정책

- **무엇이 · 왜 · 어떻게 하면 되는지** 순으로 적는다.
- 기술 용어를 쓰지 않는다. 사용자는 코드 이름을 모른다.
- 사용자를 탓하지 않는다.
- 되돌릴 길을 함께 준다 — 오류만 알리고 끝내지 않는다.

## 세부 기준

| 상황 | 문구 |
|---|---|
| 없는 주소 | `죄송합니다. 페이지를 찾을 수 없습니다.` + 홈으로 |
| 처리 중 오류 | `처리 중 문제가 발생했습니다.` + 오류 번호 + 홈으로 |
| 결과 없음 | `조건에 맞는 결과가 없습니다.` |
| 권한·상태로 막힘 | 무엇 때문에 막혔는지 그 조건을 적는다 |

## 예외

- 개발용 화면(`/docs`)은 원인을 그대로 적는다 — 읽는 사람이 만든 사람이다.

## 점검 항목

- [ ] 문구에 코드·영문 용어가 없다
- [ ] 모든 오류 화면에 돌아갈 길이 있다
