## 5. 사용자 시나리오

### 정상

- B2C · B2B · IR 도메인 필터 → 결과가 화면에 바로 반영된다.
- 플랜명 · 코드 검색 → 결과가 화면에 바로 반영된다.
- 등급별 요금 및 한도 조회 → 결과가 화면에 바로 반영된다.
- 등급별 제공 기능 비교표 조회 → 결과가 화면에 바로 반영된다.

### 인수 조건

- **Given** 이 화면을 열었을 때 **When** B2C · B2B · IR 도메인 필터 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 플랜명 · 코드 검색 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 등급별 요금 및 한도 조회 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 등급별 제공 기능 비교표 조회 **Then** 그 결과가 화면에 반영된다.

### 화면 정책

- 등록 기능을 제공하지 않습니다. 등급이 도메인별 3개로 고정되어 있어 신규 생성이 아닌 기존 등급 수정만 필요합니다.
- 탭을 도메인 기준으로 구성합니다. 판매 대상이 다르면 동일한 등급명이 서로 다른 내용을 의미합니다. B2C 의 회원 상한은 소비자 수이고 B2B 에서는 거래처 담당자 수입니다.
- 판매 중지 플랜도 표시합니다. 기존 고객사의 계약서에 해당 명칭이 기재되어 있습니다.
- 표가 아닌 카드 형태로 배치합니다. 단일 행에 배치하면 가로 스크롤이 필요합니다.
- 비교표는 행을 기능, 열을 등급으로 구성합니다. 등급별 카드로 구성하면 동일 기능명이 반복되며 등급 간 차이를 확인하기 어렵습니다.
- 관리자 기능과 고객 화면 기능을 구분하여 표시합니다. 동일 자원이라도 양쪽이 함께 제공되지 않습니다.
- 플랜명은 고객사 · 이탈 · 매출 화면에도 표시됩니다. 명칭 변경은 기준 값(설정 > 기준 값)에서 수행해야 4개 화면에 함께 반영됩니다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.

### 향후 확장

- 연간 결제 할인
- 등급별 계약 수 추이
- B2B · IR 등급 판매 개시
