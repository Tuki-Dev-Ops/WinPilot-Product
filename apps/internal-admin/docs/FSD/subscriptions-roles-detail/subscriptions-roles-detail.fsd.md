## 5. 사용자 시나리오

### 정상

- 자원별 조회 · 등록 · 삭제 · 설정 변경 권한 설정 → 결과가 화면에 바로 반영된다.
- 저장 → 결과가 화면에 바로 반영된다.
- 변경 취소 → 결과가 화면에 바로 반영된다.
- 목록으로 이동 → 결과가 화면에 바로 반영된다.

### 인수 조건

- **Given** 이 화면을 열었을 때 **When** 자원별 조회 · 등록 · 삭제 · 설정 변경 권한 설정 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 저장 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 변경 취소 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 목록으로 이동 **Then** 그 결과가 화면에 반영된다.

## 6. 예외처리

| 발생 조건 | 사용자 안내 | 화면 처리 |
|---|---|---|
| 등록되지 않은 식별자로 접근하면 404 페이지를 표시합니다. | 무엇이 왜 막혔는지 그 자리에서 알린다 | 입력값과 스크롤 자리를 지킨 채 안내만 더한다 |
| 조회 권한 없이 다른 권한만 부여한 자원이 있으면 저장하지 않습니다. | 무엇이 왜 막혔는지 그 자리에서 알린다 | 입력값과 스크롤 자리를 지킨 채 안내만 더한다 |
| 허용 권한이 하나도 없는 역할은 저장하지 않습니다. | 무엇이 왜 막혔는지 그 자리에서 알린다 | 입력값과 스크롤 자리를 지킨 채 안내만 더한다 |
| 고정 역할은 권한 항목을 비활성화합니다. | 무엇이 왜 막혔는지 그 자리에서 알린다 | 입력값과 스크롤 자리를 지킨 채 안내만 더한다 |

## 7. 검증 규칙

- 조회 권한이 없는 자원에 등록 · 삭제 · 설정 변경 권한만 부여할 수 없습니다. 목록을 조회할 수 없으면 등록한 항목도 확인할 수 없습니다.
- 허용 권한이 하나도 없는 상태로는 저장할 수 없습니다.

### 화면 정책

- 해당 자원에 없는 권한은 항목 자체를 표시하지 않습니다. 비활성 항목을 표시하면 사유를 확인해야 합니다.
- 권한 선택 즉시 저장하지 않습니다. 권한은 오설정 확인에 가장 오랜 시간이 소요되는 항목입니다.
- 삭제와 설정 변경은 허용 시 강조 색상으로 표시합니다. 복구할 수 없는 권한을 시각적으로 구분합니다.
- 최고 관리자 역할은 수정할 수 없습니다. 권한을 제한하면 해당 콘솔에서 권한을 복구할 수 있는 계정이 없어집니다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.
