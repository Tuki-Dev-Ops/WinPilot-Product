## 1. 기능 명칭

| 항목 | 내용 |
|---|---|
| 화면명 | Integration Plugin |
| 메뉴 위치 | 연동 > Plugin |
| URL | `/integrations/plugin` |
| 화면 목적 | 고객사 배포에 얹는 조각을 켜고 끈다. |
| 기대 효과 | 무엇이 밖으로 나가고 있는지를 한 화면에서 안다. |
| 고객사 배포 연동 | 고객사 배포 — 켠 조각은 고객사 화면에서 바로 돈다. |
| Figma 페이지 순번 | 42 |

여기서 정한 값이 반영되는 고객사의 배포다. 틀리면 고객사 사이트가 통째로 멈추고, 원인을 찾는 것도 우리 몫이 된다.

### 화면 구성

| 영역 | 용도 | 표시 조건 |
|---|---|---|
| 고객사 목록 | 고객사마다 배포 도메인과 플랜을 함께 읽는다. 줄을 누르면 아래가 그 고객사의 것으로 바뀐다 | — |

| 조각 켜고 끄기 | 해당 요소를 누르거나 값을 넣는다 | 조건을 확인하고 결과를 화면에 반영한다 |
| 연동 키 넣기 | 해당 요소를 누르거나 값을 넣는다 | 조건을 확인하고 결과를 화면에 반영한다 |
| 저장 | 해당 요소를 누르거나 값을 넣는다 | 조건을 확인하고 결과를 화면에 반영한다 |

## 5. 사용자 시나리오

### 정상

- 고객사 고르기 → 결과가 화면에 바로 반영된다.
- 조각 켜고 끄기 → 결과가 화면에 바로 반영된다.
- 연동 키 넣기 → 결과가 화면에 바로 반영된다.
- 저장 → 결과가 화면에 바로 반영된다.

### 인수 조건

- **Given** 이 화면을 열었을 때 **When** 고객사 고르기 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 조각 켜고 끄기 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 연동 키 넣기 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 저장 **Then** 그 결과가 화면에 반영된다.

## 6. 예외처리

| 발생 조건 | 사용자 안내 | 화면 처리 |
|---|---|---|
| 켜 두었는데 키가 필요한 조각의 키가 비면 저장하지 않는다. | 무엇이 왜 막혔는지 그 자리에서 알린다 | 입력값과 스크롤 자리를 지킨 채 안내만 더한다 |

## 7. 검증 규칙

- 키가 필요한 조각은 켜 두었을 때 키가 있어야 한다.

### 화면 정책

- 고객사 목록이 먼저 선다 — 선택기 하나로는 어느 고객사에 무엇이 켜져 있는지 알 수 없어, 고객사를 하나씩 골라 봐야 했다.
- 한 번에 한 고객사만 본다. 목록의 체크는 고르기가 아니라 지금 보고 있는 곳이라 전체 선택 단추를 두지 않는다.
- 보이지 않는 조각을 목록에서 숨기지 않는다 — 켠 사실을 잊으면 무엇이 나가는지 아무도 모른다.
- 플랜이 열어 주지 않는 조각은 최소 플랜을 함께 적는다.
- 키가 필요 없는 조각에는 빈 칸을 그리지 않는다 — 무엇을 채워야 할지 흐려진다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.
