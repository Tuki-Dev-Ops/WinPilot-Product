## 5. 사용자 시나리오

### 정상

- B2C · B2B · IR 도메인 필터 → 결과가 화면에 바로 반영된다.
- 역할명 · 담당 범위 검색 → 결과가 화면에 바로 반영된다.
- 목록 항목 선택 시 상세 권한 화면으로 이동 → 결과가 화면에 바로 반영된다.

### 인수 조건

- **Given** 이 화면을 열었을 때 **When** B2C · B2B · IR 도메인 필터 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 역할명 · 담당 범위 검색 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 목록 항목 선택 시 상세 권한 화면으로 이동 **Then** 그 결과가 화면에 반영된다.

## 7. 검증 규칙

_N/A — 이 화면에는 해당되지 않습니다._

### 화면 정책

- 탭을 도메인 기준으로 구성합니다. 판매 대상이 다르면 관리 자원도 다릅니다. B2C 의 주문에 해당하는 자원이 B2B 에서는 견적과 발주이며 IR 에는 해당 자원이 없습니다.
- 자원 × 역할 전체 표를 목록 하단에 제공하지 않습니다. 자원 15개 × 동작 4개는 60개 항목이므로 역할 수 확인이 목적인 사용자에게 불필요합니다.
- 역할은 사전 정의 항목입니다. 고객사가 직접 생성하도록 하면 명칭만 다른 역할이 다수 생성됩니다.
- 허용 권한 수를 전체 권한 수와 함께 표시합니다. 건수만으로는 권한 범위를 판단할 수 없습니다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.
