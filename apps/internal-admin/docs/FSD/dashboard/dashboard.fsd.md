## 5. 사용자 시나리오

### 정상

- 요약 카드에서 그 수치를 만든 목록으로 이동 → 결과가 화면에 바로 반영된다.
- 만료가 임박한 고객사 열기 → 결과가 화면에 바로 반영된다.
- 연체·문의 줄에서 해당 목록으로 이동 → 결과가 화면에 바로 반영된다.

### 인수 조건

- **Given** 이 화면을 열었을 때 **When** 요약 카드에서 그 수치를 만든 목록으로 이동 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 만료가 임박한 고객사 열기 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 연체·문의 줄에서 해당 목록으로 이동 **Then** 그 결과가 화면에 반영된다.

## 6. 예외처리

| 발생 조건 | 사용자 안내 | 화면 처리 |

## 7. 검증 규칙

_N/A — 이 화면에는 해당되지 않습니다._

### 화면 정책

- 카드를 누르면 그 수치를 만든 조건이 그대로 걸린 목록으로 간다.
- 기준일은 서버에서 한 번 정해 내려보낸다 — 화면이 스스로 읽으면 서버·브라우저 값이 어긋난다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.
