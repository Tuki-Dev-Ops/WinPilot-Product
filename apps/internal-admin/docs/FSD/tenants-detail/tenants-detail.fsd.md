## 1. 기능 명칭

| 항목 | 내용 |
|---|---|
| 화면명 | Tenant Detail |
| 메뉴 위치 | 고객사 > (목록에서 진입) |
| URL | `/tenants/[tenantId]` · 예 `/tenants/T-101` |
| 화면 목적 | 개별 고객사의 계약 · 배포 · 청구 정보를 제공하는 고객사 상세 페이지입니다. |
| 배경 | — |
| 기대 효과 | 고객사 문의 접수 시 여러 화면을 이동하지 않고 본 화면에서 확인할 수 있습니다. |
| 고객사 배포 연동 | 고객사 배포 — 본 화면에 표시된 도메인과 계정이 실제 배포 정보입니다. |
| Figma 페이지 순번 | 15 |

여기서 정한 값이 반영되는 고객사의 배포다. 틀리면 고객사 사이트가 통째로 멈추고, 원인을 찾는 것도 우리 몫이 된다.

## 5. 사용자 시나리오

### 정상

- 고객사 기본 정보 조회 → 결과가 화면에 바로 반영된다.
- 배포 및 계정 조회 → 결과가 화면에 바로 반영된다.
- 청구 내역 조회 → 결과가 화면에 바로 반영된다.
- 담당자 및 활동 이력 조회 → 결과가 화면에 바로 반영된다.
- 해당 고객사의 연동 설정으로 이동 → 결과가 화면에 바로 반영된다.

### 인수 조건

- **Given** 이 화면을 열었을 때 **When** 고객사 기본 정보 조회 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 배포 및 계정 조회 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 청구 내역 조회 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 담당자 및 활동 이력 조회 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 해당 고객사의 연동 설정으로 이동 **Then** 그 결과가 화면에 반영된다.

### 화면 정책

- 조회 전용 화면입니다. 수정은 각 관리 화면에서 수행합니다.
- 담당자와 활동 이력을 본 화면에도 제공합니다. 목록에서만 조회 가능하면 상세 화면을 벗어나야 합니다.
- 연락처와 이메일을 마스킹하지 않습니다. 직접 연락에 사용하는 값이며 사내 전용 화면입니다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.

### 향후 확장

- 배포 상태 실시간 조회
