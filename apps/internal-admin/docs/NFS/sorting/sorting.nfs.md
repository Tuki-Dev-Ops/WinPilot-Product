# 정렬

> Internal Admin · 생성: `pnpm docs:build` · 원본: `tools/docs/nfs.ts`

## 목적

기본 정렬이 화면마다 다르면 같은 자료가 다른 순서로 보인다.

## 적용 범위

목록 화면.

## 정책

- 기본 정렬은 **최신순**이다. 새로 생긴 것을 먼저 보는 것이 대부분의 경우 맞다.
- 사용자가 고른 정렬은 주소에 남긴다.
- 정렬이 같은 값끼리는 id 로 한 번 더 갈라 순서가 흔들리지 않게 한다.

## 세부 기준

| 목록 | 기본 정렬 |
|---|---|
| 공지·뉴스·문의 | 등록 최신순 |
| 상품 | 진열 순서(어드민이 정한 순서) |
| 주문 | 주문일 최신순 |
| 쿠폰 | 사용 가능 → 사용 완료 → 만료 |

## 예외

- 어드민이 순서를 직접 정하는 목록은 그 순서를 따른다.

## 점검 항목

- [ ] 같은 값이 있어도 순서가 흔들리지 않는다
- [ ] 고른 정렬이 주소에 남는다
