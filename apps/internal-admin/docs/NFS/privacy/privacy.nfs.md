# 개인정보

> Internal Admin · 생성: `pnpm docs:build` · 원본: `tools/docs/nfs.ts`

## 목적

화면에 그대로 드러난 개인정보는 어깨너머로도 새어 나간다.

## 적용 범위

사람의 정보를 보여 주는 모든 화면.

## 정책

- 목록에서는 **가려서** 보여 준다. 전부 필요한 자리가 아니면 일부만 드러낸다.
- 수집하는 값이 무엇인지 그 자리에서 알리고, 동의한 내용을 언제든 다시 읽을 수 있게 한다.
- 이 프로젝트는 프론트엔드 전용이라 **실제 개인정보를 담지 않는다.** 화면의 값은 모두 예시다.

## 세부 기준

| 항목 | 표시 방법 |
|---|---|
| 이메일 | 앞 두 글자 + `***` + 도메인 |
| 전화번호 | 가운데 자리 `****` |
| 이름 | 가운데 글자 `*` |
| 주소 | 상세 주소는 상세 화면에서만 |
| 비밀번호 | 어떤 자리에서도 보여 주지 않는다 |

## 예외

- 본인이 자기 정보를 보는 화면(마이페이지)에서는 가리지 않는다.

## 점검 항목

- [ ] 목록에 가려지지 않은 개인정보가 없다
- [ ] 동의 내용을 다시 읽을 길이 있다
