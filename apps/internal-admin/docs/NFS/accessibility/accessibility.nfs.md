# 접근성

> Internal Admin · 생성: `pnpm docs:build` · 원본: `tools/docs/nfs.ts`

## 목적

눈으로만, 마우스로만 쓸 수 있는 화면은 쓸 수 없는 사람을 만든다. 못 쓰는 사람이 생기는 것을 막는 기준이다.

## 적용 범위

모든 화면의 모든 요소.

## 정책

- **색만으로 상태를 알리지 않는다.** 모양이나 글자를 함께 둔다 — 색각 이상 사용자에게 빨강·초록은 같은 회색이다.
- 키보드만으로 모든 요소에 닿을 수 있고, 지금 어디에 있는지 눈에 보인다.
- 누르는 것에는 눌러서 알 수 있는 이름을 준다. 아이콘만 있는 단추에는 `aria-label` 을 붙인다.
- 뜻을 담지 않는 장식(도형·삽화)은 `aria-hidden` 으로 읽히지 않게 한다.
- 모션 감소를 켠 사용자에게는 자동 넘김·전환이 돌지 않는다.

## 세부 기준

| 항목 | 기준 |
|---|---|
| 본문 대비 | 4.5:1 이상 |
| 큰 글자(18px 이상 굵게) | 3:1 이상 |
| 포커스 표시 | 테두리만이 아니라 배경이나 굵기로도 갈린다 |
| 탭 순서 | 화면에 보이는 순서와 같다 |
| 이미지 대체 텍스트 | 무엇이 보이는지 적는다. 장식이면 빈 값 |
| 상태 알림 | 색 + (모양 | 글자) |

## 예외

- 캡처 그림은 문서용이라 대체 텍스트에 화면 이름과 너비만 적는다 — 그림 속 글자를 옮겨 적지 않는다.

## 점검 항목

- [ ] 탭만으로 첫 요소부터 마지막 요소까지 닿는다
- [ ] 포커스가 보이지 않는 요소가 없다
- [ ] 색을 지워도 상태가 구분된다
- [ ] 모션 감소를 켜면 자동 넘김이 멈춘다
- [ ] 아이콘만 있는 단추에 이름이 있다
