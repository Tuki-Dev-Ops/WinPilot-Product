# 검색

> Internal Admin · 생성: `pnpm docs:build` · 원본: `tools/docs/nfs.ts`

## 목적

검색 조건이 사라지면 사용자는 같은 조건을 다시 만든다.

## 적용 범위

목록 화면.

## 정책

- 검색어는 **주소에 남긴다.** 새로고침·공유·뒤로가기에서 살아남아야 조건을 말로 설명하지 않는다.
- 검색어가 비면 조건이 없는 것으로 본다 — 목록을 비우지 않는다.
- 결과가 없으면 목록 자리에 한 줄로 알리고, 조건을 지울 길을 준다.

## 세부 기준

| 항목 | 기준 |
|---|---|
| 대상 | 화면마다 명세에 적는다 (이름·번호 등) |
| 대소문자 | 가리지 않는다 |
| 앞뒤 공백 | 지우고 본다 |
| 주소 파라미터 | `q` |
| 전역 검색 | **현재 미사용.** 도입하면 화면별 검색과 대상이 겹치지 않게 나눈다 |

## 예외

- 문서 화면에는 검색이 없다 — 사이드바 목록이 곧 전체다.

## 점검 항목

- [ ] 새로고침해도 조건이 남는다
- [ ] 빈 검색어가 목록을 비우지 않는다
- [ ] 결과 없음 안내가 있다
