# 유지보수

> Internal Admin · 생성: `pnpm docs:build` · 원본: `tools/docs/nfs.ts`

## 목적

문서가 화면을 따라오지 못하면 그 문서는 곧 거짓말이 된다.

## 적용 범위

이 문서 묶음 전체.

## 정책

- 명세는 **생성물**이다. 원본은 코드 안에 있고, 문서를 손으로 고치면 다음 생성 때 지워진다.
- 화면을 늘리면 매니페스트·명세·캡처가 함께 자란다. 하나라도 빠지면 검사에서 잡힌다.
- 생성물을 커밋하지 않으면 CI 가 막는다 — 저장소의 문서가 화면보다 뒤처진 채로 남지 않게.

## 세부 기준

| 검사 | 무엇을 보는가 |
|---|---|
| `pnpm spec:check` | 등록·명명 규칙 |
| `pnpm sync:check` | 레지스트리 이름과 실제 파일 이름 |
| `pnpm docs:build` | 명세 생성 · 어긋나면 CI 가 막는다 |
| `pnpm docs:capture` | 화면 캡처 다시 뜨기 |
| `pnpm typecheck` · `pnpm build` | 타입과 빌드 |

## 예외

- 캡처는 CI 에서 돌리지 않는다 — 글꼴·안티앨리어싱이 러너마다 달라 매번 다른 그림이 나온다.

## 점검 항목

- [ ] 원본을 고치고 생성물을 함께 커밋했다
- [ ] CI 가 통과했다
