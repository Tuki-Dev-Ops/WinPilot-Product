# 파일 업로드

> Internal Admin · 생성: `pnpm docs:build` · 원본: `tools/docs/nfs.ts`

## 목적

올릴 수 있는 것과 없는 것을 미리 알려야 올리고 나서 거절당하지 않는다.

## 적용 범위

이미지를 올리는 화면.

## 정책

- **고를 수 있게 되기 전에** 무엇을 올릴 수 있는지 적어 둔다.
- 거절할 때는 무엇이 걸렸는지(형식·크기·비율) 그대로 알린다.
- 올린 뒤에는 미리보기를 보여 준다 — 잘못 고른 것을 그 자리에서 안다.

## 세부 기준

| 항목 | 기준 |
|---|---|
| 형식 | PNG · JPG · WEBP |
| 크기 | 한 장 5MB 이하 |
| 비율 | 자리마다 정해진 비율(16:9 · 21:9 등)에서 벗어나면 알린다 |
| 개수 | 자리마다 정한 수를 넘지 않는다 |

## 예외

- 고객 화면에는 업로드가 없다 — 값은 모두 어드민에서 들어온다.

## 점검 항목

- [ ] 고르기 전에 기준이 보인다
- [ ] 거절 사유가 구체적이다
- [ ] 미리보기가 뜬다
