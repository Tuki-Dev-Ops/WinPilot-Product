# 반응형

> Internal Admin · 생성: `pnpm docs:build` · 원본: `tools/docs/nfs.ts`

## 목적

너비마다 다른 화면을 만들면 같은 화면이 여러 벌이 되어 한쪽만 고쳐진다.

## 적용 범위

모든 화면.

## 정책

- 확정된 세 너비(Desktop 1440 · Tablet 768 · Mobile 375)에서 **가로 스크롤이 생기지 않는다.**
- 너비가 바뀌어도 **화면이 하는 일은 같다.** 좁다고 기능을 빼지 않고 배치만 바꾼다.
- 넓은 표처럼 줄일 수 없는 것은 그 요소 안에서만 가로로 스크롤한다 — 페이지 전체가 밀리지 않게.
- 뜻을 담지 않는 장식은 좁은 화면에서 뺀다. 자리만 차지한다.

## 세부 기준

| 너비 | 기준 |
|---|---|
| Desktop 1440px | 가로 스크롤 없음 · 주요 동작 모두 가능 |
| Tablet 768px | 가로 스크롤 없음 · 주요 동작 모두 가능 |
| Mobile 375px | 가로 스크롤 없음 · 주요 동작 모두 가능 |
| 표·코드·도면 | 자기 상자 안에서 가로 스크롤 |
| 단추 두 개 이상 | 좁은 화면에서 세로로 쌓고 너비를 채운다 |

## 예외

- 도면(mermaid)은 줄이면 글자가 뭉개지므로 원래 크기로 두고 카드 안에서 스크롤한다.

## 점검 항목

- [ ] 세 너비에서 `document.body` 가로 스크롤이 없다
- [ ] 좁은 화면에서 빠진 기능이 없다
- [ ] 표가 페이지를 밀지 않는다
