# 알림

> B2C Client 템플릿 A · 생성: `pnpm docs:build` · 원본: `tools/docs/nfs.ts`

## 목적

알림이 여러 곳에서 뜨면 어디를 봐야 할지 모른다.

## 적용 범위

모든 화면.

## 정책

- 토스트는 **화면 하단 정중앙 한 곳**에서만 뜬다.
- 토스트는 스스로 사라진다. 사용자가 지워야만 사라지는 것은 오류 화면으로 다룬다.
- 읽지 않은 수는 아이콘 옆 숫자로 붙인다 — 색만으로 알리지 않는다.

## 세부 기준

| 종류 | 자리 | 지속 |
|---|---|---|
| 성공·정보 | 하단 정중앙 토스트 | 약 2~3초 |
| 입력 오류 | 해당 입력 아래 | 고칠 때까지 |
| 확인이 필요한 일 | 모달 | 고를 때까지 |
| 푸시 알림 | **현재 미사용.** 서버가 없어 보낼 곳이 없다 | — |

## 예외

- 알람 화면 자체는 목록이라 토스트를 쓰지 않는다.

## 점검 항목

- [ ] 토스트가 한 자리에서만 뜬다
- [ ] 읽지 않은 수가 숫자로도 보인다
