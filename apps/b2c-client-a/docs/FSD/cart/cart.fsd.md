## 4. 버튼 및 이벤트

| 버튼 | 눌렀을 때 | 성공 | 실패 |
|---|---|---|---|
| 선택 삭제 | 선택한 항목을 장바구니에서 제거한다 | 목록과 합계를 다시 계산한다 | 선택한 항목이 없으면 버튼을 비활성화한다 |
| 주문하기 | 선택한 항목만 주문서 화면으로 전달한다 | `/orders/new` 로 이동한다 | 선택한 항목이 없으면 버튼을 비활성화한다 |

## 5. 사용자 시나리오

### 정상

- 수량 수정 → 결과가 화면에 바로 반영된다.
- 선택 항목 삭제 → 결과가 화면에 바로 반영된다.
- 주문서 화면으로 이동 → 결과가 화면에 바로 반영된다.

### 인수 조건

- **Given** 이 화면을 열었을 때 **When** 수량 수정 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 선택 항목 삭제 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 주문서 화면으로 이동 **Then** 그 결과가 화면에 반영된다.

## 6. 예외처리

| 발생 조건 | 사용자 안내 | 화면 처리 |
|---|---|---|
| 품절 항목은 합계에서 제외하고 주문 대상에서 제외합니다. 목록에서는 숨기지 않고 표시합니다. | 무엇이 왜 막혔는지 그 자리에서 알린다 | 입력값과 스크롤 자리를 지킨 채 안내만 더한다 |
| 수량은 재고 수량을 초과할 수 없습니다. | 무엇이 왜 막혔는지 그 자리에서 알린다 | 입력값과 스크롤 자리를 지킨 채 안내만 더한다 |

## 7. 검증 규칙

- 수량은 1 이상이며 재고를 초과할 수 없습니다.
- 선택한 항목이 없으면 주문 및 삭제 버튼을 비활성화합니다.

### 화면 정책

- 비회원도 장바구니에 담을 수 있습니다. 로그인은 주문 단계에서 요구합니다.
- 담은 이후 품절된 상품은 목록에 유지하되 선택할 수 없도록 처리하고 사유를 표시합니다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.

### 향후 확장

- 장바구니 보관 기간 및 복구. 현재는 브라우저 종료 시 초기화됩니다.
