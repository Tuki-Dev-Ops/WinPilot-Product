| 항목 | 내용 |
|---|---|
| 화면명 | Product Detail |

## 3. 기능 명세

| 수량 조절 | 해당 요소를 누르거나 값을 넣는다 | 조건을 확인하고 결과를 화면에 반영한다 |
| 장바구니 담기 | 해당 요소를 누르거나 값을 넣는다 | 조건을 확인하고 결과를 화면에 반영한다 |
| 바로 구매 | 해당 요소를 누르거나 값을 넣는다 | 조건을 확인하고 결과를 화면에 반영한다 |
| 설명·리뷰 탭 전환 | 해당 요소를 누르거나 값을 넣는다 | 조건을 확인하고 결과를 화면에 반영한다 |

### 데이터 항목

| 항목 | 설명 | 입력 형태 | 필수 | 형식·제한 | 예시 |
|---|---|---|---|---|---|

## 4. 버튼 및 이벤트

| 버튼 | 눌렀을 때 | 성공 | 실패 |
|---|---|---|---|
| 장바구니 담기 | 고른 옵션과 수량을 담는다 | 토스트로 알리고 장바구니 수가 오른다 | 옵션을 고르지 않았으면 그 자리에서 알린다 |
| 바로 결제 | 결제 화면으로 그 상품만 들고 간다 | `/orders/new?productId=…` 로 이동 | 옵션 미선택이면 단추가 잠겨 있다 |

## 5. 사용자 시나리오

### 정상

- 색상 → 사이즈 순서로 옵션 고르기 → 결과가 화면에 바로 반영된다.
- 수량 조절 → 결과가 화면에 바로 반영된다.
- 장바구니 담기 → 결과가 화면에 바로 반영된다.
- 바로 구매 → 결과가 화면에 바로 반영된다.
- 설명·리뷰 탭 전환 → 결과가 화면에 바로 반영된다.

### 인수 조건

- **Given** 이 화면을 열었을 때 **When** 색상 → 사이즈 순서로 옵션 고르기 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 수량 조절 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 장바구니 담기 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 바로 구매 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 설명·리뷰 탭 전환 **Then** 그 결과가 화면에 반영된다.

## 6. 예외처리

| 발생 조건 | 사용자 안내 | 화면 처리 |
|---|---|---|
| 옵션이 있는 상품은 고르기 전에 담을 수 없다. | 무엇이 왜 막혔는지 그 자리에서 알린다 | 입력값과 스크롤 자리를 지킨 채 안내만 더한다 |
| 재고 0 옵션은 누를 수 없고 취소선으로 표시한다. | 무엇이 왜 막혔는지 그 자리에서 알린다 | 입력값과 스크롤 자리를 지킨 채 안내만 더한다 |
| 수량은 재고를 넘지 못한다. | 무엇이 왜 막혔는지 그 자리에서 알린다 | 입력값과 스크롤 자리를 지킨 채 안내만 더한다 |

## 7. 검증 규칙

- 옵션을 고르지 않으면 두 단추 모두 잠긴다.
- 수량은 1 이상이며 고른 옵션의 재고를 넘지 못한다.
- 재고 0 옵션은 목록에는 남기되 고를 수 없고 취소선으로 표시한다 — 왜 못 고르는지 보여야 한다.

### 화면 정책

- 판매중지·숨김 상품은 주소로 직접 들어와도 열리지 않는다.
- 리뷰는 어드민이 숨긴 것(`visible: false`)이 오지 않는다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.
