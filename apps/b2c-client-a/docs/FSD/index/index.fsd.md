## 5. 사용자 시나리오

### 정상

- 메인 배너 슬라이드 조회 → 결과가 화면에 바로 반영된다.
- 카테고리 바로가기 선택 시 상품 목록으로 이동 → 결과가 화면에 바로 반영된다.
- 신상품 · 베스트 영역에서 상품 상세로 이동 → 결과가 화면에 바로 반영된다.
- 카테고리 메뉴 선택 → 결과가 화면에 바로 반영된다.

### 인수 조건

- **Given** 이 화면을 열었을 때 **When** 메인 배너 슬라이드 조회 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 카테고리 바로가기 선택 시 상품 목록으로 이동 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 신상품 · 베스트 영역에서 상품 상세로 이동 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 카테고리 메뉴 선택 **Then** 그 결과가 화면에 반영된다.

### 화면 정책

- 메인 배너는 목록을 반복 배치하여 마지막 슬라이드에서 끊기지 않도록 처리합니다.
- 상품 슬라이드는 가로 스크롤바 대신 페이지 표시(n/total)를 사용합니다.
- 게시 기간이 종료된 배너는 화면에서 숨기지 않고 조회 단계에서 제외합니다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.

### 향후 확장

- 개인화 추천 영역. 현재는 전체 사용자에게 동일한 목록을 제공합니다.
- 배너 노출 비율 설정. 관리자에 해당 항목이 추가되면 연동합니다.
