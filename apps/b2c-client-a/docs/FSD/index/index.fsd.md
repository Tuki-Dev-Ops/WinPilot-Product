## 7. 사용자 시나리오

**정상**

- 히어로 배너 넘김(자동·수동) → 결과가 화면에 바로 반영된다.
- 바로가기 타일로 분류 이동 → 결과가 화면에 바로 반영된다.
- 신상품·베스트 줄에서 상품 열기 → 결과가 화면에 바로 반영된다.
- 카테고리 탐색 → 결과가 화면에 바로 반영된다.

**예외**

- 노출 기간이 끝난 배너는 오지 않는다.
- 숨김 상품은 어느 줄에도 나오지 않는다.

## 8. 예외 처리

| 숨김 상품은 어느 줄에도 나오지 않는다. | 무엇이 왜 막혔는지 그 자리에서 알린다 | 입력값과 스크롤 자리를 지킨 채 안내만 더한다 |

## 10. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

## 11. UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.

## 12. 화면 정책

- 히어로는 목록을 여러 벌 이어 붙여 끝에서 끊기지 않는다(무한 반복).
- 상품 줄은 가로 스크롤바 대신 장 표시(n/total)를 쓴다.
- 노출 기간이 지난 배너는 목록에 오지 않는다 — 화면에서 숨기지 않고 아예 받지 않는다.

## 13. 인수 조건

- **Given** 이 화면을 열었을 때 **When** 바로가기 타일로 분류 이동 **Then** 그 결과가 화면에 반영된다.

- **Given** 이 화면을 열었을 때 **When** 카테고리 탐색 **Then** 그 결과가 화면에 반영된다.
