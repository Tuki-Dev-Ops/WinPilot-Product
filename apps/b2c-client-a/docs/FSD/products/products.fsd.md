## 5. 사용자 시나리오

### 정상

- 1Depth · 2Depth 분류 필터 → 결과가 화면에 바로 반영된다.
- 상품명 검색 → 결과가 화면에 바로 반영된다.
- 필터 영역에서 분류 및 가격 범위 적용 → 결과가 화면에 바로 반영된다.
- 상품 선택 시 상세 페이지로 이동 → 결과가 화면에 바로 반영된다.

### 인수 조건

- **Given** 이 화면을 열었을 때 **When** 1Depth · 2Depth 분류 필터 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 상품명 검색 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 필터 영역에서 분류 및 가격 범위 적용 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 상품 선택 시 상세 페이지로 이동 **Then** 그 결과가 화면에 반영된다.

## 6. 예외처리

| 발생 조건 | 사용자 안내 | 화면 처리 |
|---|---|---|
| 2Depth 는 선택한 1Depth 하위 항목만 유효합니다. 조합이 맞지 않으면 조건에서 제외합니다. | 무엇이 왜 막혔는지 그 자리에서 알린다 | 입력값과 스크롤 자리를 지킨 채 안내만 더한다 |
| 가격 입력이 숫자가 아니면 조건에서 제외합니다. 목록을 비우지 않습니다. | 무엇이 왜 막혔는지 그 자리에서 알린다 | 입력값과 스크롤 자리를 지킨 채 안내만 더한다 |

## 7. 검증 규칙

- 가격 입력이 숫자가 아니면 오류로 처리하지 않고 조건에서 제외합니다. 목록을 비우지 않습니다.
- 최저가가 최고가보다 크면 두 값을 교체하여 적용합니다.
- 2Depth 가 선택한 1Depth 하위 항목이 아니면 조건에서 제외합니다.

### 화면 정책

- 분류 · 검색어 · 가격 · 페이지를 모두 URL 파라미터로 유지합니다. 새로고침 · 공유 · 뒤로가기에서 조건이 유지되어야 합니다.
- 기본 정렬은 관리자에 등록된 진열 순서입니다.
- 신상품과 베스트는 별도 화면이 아니라 본 목록의 필터(`?tag=NEW|BEST`)로 처리합니다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.

### 향후 확장

- 정렬 기준 선택(가격순 · 판매순). 현재는 진열 순서 1개입니다.
