# 고객 화면 연동 — 본 콘솔에서 관리하는 데이터의 반영 위치

본 저장소에는 서버가 없습니다. 본 콘솔에서 저장한 값이 사이트에 반영되는 것은 두 앱이
**동일한 모듈을 조회**하기 때문이며 통신에 의한 것이 아닙니다.

```mermaid
flowchart LR
  A[IR Admin · 3303] -->|저장| S[(packages/store · ir.ts · site.ts)]
  S -->|조회| C[IR Client · 3304]
```

## 관리 대상 데이터 구성

데이터가 두 파일로 구분되어 있으며 성격이 다릅니다.

| 파일 | 관리 대상 | 오류 발생 시 |
|---|---|---|
| `site.ts` | 제품 · 콘텐츠 · 배너 · 설정 | 재입력으로 처리 |
| ~~`ir.ts`~~ | ~~공시 · 재무 · 주주 · 자료~~ | **본 콘솔에서 조회하지 않음** — 화면 10개 삭제 |

`ir.ts` 를 관리하던 화면 10개(공시 · 재무 · 주주 · 자료)를 삭제하였습니다. 삭제 경위는
`lib/navigation/ir-menu.ts` 에 기재되어 있습니다. **투자자 사이트는 해당 데이터를 계속
조회하고 있으나** 저장소에 수정 화면이 없습니다.

---

## 1. 대응표 — 본 콘솔에서 수정하면 사이트에 반영되는 항목

| 관리 화면 | 데이터 | 사이트 화면 |
|---|---|---|
| 콘텐츠 > 공지사항 | `SITE_NOTICES` | 고객지원 — 공지사항 |
| 콘텐츠 > 뉴스 | `MEDIA_CLIPS` | 고객지원 — 뉴스 |
| 콘텐츠 > FAQ | `SITE_FAQS` | 고객지원 — FAQ |
| 제품 > 목록 · 설정 | `SOLUTIONS` | 제품 · 솔루션 상세 4개 |
| 서비스 > 목록 · 설정 | `SERVICE_DETAILS` | 솔루션 상세 2개(컨설팅 · 인프라) |
| 회사 > 연혁 | `MILESTONES` | 회사 소개 · 연혁 |
| 회사 > 특허 및 인증 | `CREDENTIALS` | 회사 소개 · 특허 및 인증 |
| 배너 > 팝업 | `SITE_BANNERS` `slot = 팝업` | **전 화면에 표시되는 팝업** |
| 문의 > 설정 | `SITE_INQUIRY_KINDS` · `SITE_REGIONS` | 고객지원 — 문의하기의 선택 항목 |
| *(메뉴 미등록)* `/solutions` | `SITE_SERVICES` | 제품 화면의 서비스 영역 |

문의는 데이터 흐름이 반대입니다. **사이트에서 접수하고 본 콘솔에서 조회**합니다(`SITE_INQUIRIES`).

`(메뉴 미등록)` 은 사이드바에 항목이 없어 **URL 로 직접 접근해야 하는** 화면입니다. 해당
화면 목록은 [Path 정의서](/docs/path) §5 에 기재되어 있습니다.

---

## 2. 본 콘솔에서 수정해도 사이트에 반영되지 않는 항목

저장은 처리되나 사이트에 반영되지 않는 항목입니다.

| 관리 화면 | 데이터 | 사유 |
|---|---|---|
| 설정 > SEO 정보 | `SITE_SEO` | 사이트에서 조회하지 않음 |
| 설정 > 공급자 정보 | `SITE_SUPPLIER` | 사이트 푸터는 `IR_COMPANY` 를 조회. **대표이사 값이 이미 불일치** |
| 설정 > 이용약관 · 개인정보 처리방침 | `LEGAL_DOCS` | 사이트의 `/terms` · `/privacy` 는 화면에서 관리하는 내용을 표시 — **동일 문서가 두 곳에서 관리됨** |
| 설정 > 국문 · 영문 | `LOCALE_PAIRS` | 사이트에 영문 화면이 없음 |
| 회사 > 소개 | `SITE_INTRO` | 사이트 메인의 회사 소개 영역이 해당 값을 조회하지 않음 |
| 배너 > 메인 비주얼 | `SITE_BANNERS` `slot = 메인 비주얼` | 사이트 메인 배너가 `HERO_SLIDES` 를 표시 |

**통계 3개 화면은 본 표에 포함하지 않습니다.** 조회 전용 화면이므로 사이트 반영 대상이
아닙니다.

---

## 3. 사이트에 노출되나 **본 콘솔에 관리 화면이 없는** 항목

| 데이터 | 사이트 화면 | 관리자 |
|---|---|---|
| `DISCLOSURES` | 공시 목록 · 공시 상세 | 화면 삭제 |
| `FINANCIALS` · `DIVIDENDS` · `STOCK` | 재무정보 · 배당정보 · 주가정보 | 동일 |
| `MEETINGS` | 주주총회 · 전자투표 | 동일 |
| `OFFICERS` · `SHAREHOLDERS` | 지배구조 | 동일 |
| `IR_DOCUMENTS` · `IR_SCHEDULES` · `SUBSCRIBERS` | 자료실 · IR 일정 · 알림 신청 | 동일 |
| `IR_COMPANY` | **전 화면의 푸터** · 회사 소개 · 오시는 길 | 최초부터 없음 |
| `HERO_SLIDES` | 홈 메인 배너 | 동일 |
| `DIRECTIONS` | 오시는 길 | 동일 |

**본 표가 현재 콘솔의 주요 제약 사항입니다.** 사이트에 노출되는 데이터의 절반을 저장소에서
수정할 수 없습니다. 공시와 재무 관련 화면은 목록 조회만 제공하고 등록 기능이 없는 조회 전용
화면이었으며 해당 목록 화면도 삭제되었습니다.

해당 화면을 사이트에서도 제외하기로 결정하는 시점에 `ir.ts` 를 함께 삭제합니다. 현재는
**사이트에서 계속 조회하고 있으므로** 데이터를 유지합니다. 데이터를 먼저 삭제하면 사이트에
빈 목록이 표시됩니다.

---

## 4. 복구할 수 없는 처리

없습니다. **공시 게시가 유일한 해당 처리였으며 해당 화면은 삭제되었습니다.**

나머지 저장 처리는 재입력으로 복구할 수 있으며 삭제는 확인 모달을 거칩니다.

---

## 5. 조회 단계에서 제외되는 항목

사이트에서 별도로 판단하지 않습니다. store 의 공개 필터가 일괄 처리합니다.

| 필터 | 제외 대상 |
|---|---|
| `publicDisclosures()` | `작성 중` · `검토 요청`. **`공시됨` 과 `정정` 만 조회하며 URL 직접 접근도 제한** |
| `publicSiteNotices()` | 비공개 공지. 상단 고정 항목 우선 배치 |
| `publicMediaClips()` | 비공개 뉴스 |
| `publicSiteFaqs()` | 비공개 FAQ |
| `publicCredentials()` | 비공개 특허 · 인증 |
| `publicSolutions()` | 비노출 제품 |
| `liveSitePopups()` | 게시 기간 외 또는 비노출 설정 항목 |

필터를 화면별로 정의하지 않는 사유는 신규 화면 추가 시 해당 처리가 누락되면 비노출 항목이
해당 화면에만 표시되기 때문입니다.

---

## 6. 팝업 노출 규칙

`scheduleState()` 가 **게시 기간을 기준으로** 판정합니다. 운영자가 직접 설정하는 항목은
`숨김` 1개입니다. 행사 종료 후 수동 해제가 누락되는 것을 방지하기 위한 것입니다. B2C 배너와
**동일한 함수**를 사용합니다.

| 상태 | 정의 |
|---|---|
| `노출 중` | 현재 게시 중 |
| `예정` | 시작일 이전 |
| `종료` | 종료일 경과 |
| `숨김` | 운영자가 비노출로 설정. 게시 기간과 무관 |

- 게시 중인 팝업이 복수여도 **한 번에 하나만** 표시합니다. 닫으면 다음 항목을 표시합니다.
- **본문이 필수**입니다. 제목만 표시되는 팝업은 안내 내용을 전달할 수 없습니다.
- 표시 위치 선택 항목을 제공하지 않습니다. 휴무와 처리방침 개정 등 확인이 필요한 안내만
  게시하므로 화면 모서리에 배치하면 열람률이 저하됩니다.
- `오늘 하루 보지 않기` 설정은 **사용자 브라우저에만** 저장됩니다. 본 콘솔에서 조회할 수 없습니다.
