## 5. 사용자 시나리오

### 정상

- 다국어 문구 목록 조회 → 결과가 화면에 바로 반영된다.
- 목록 항목 선택 시 수정 모달 표시 → 결과가 화면에 바로 반영된다.
- 저장 → 결과가 화면에 바로 반영된다.

### 인수 조건

- **Given** 이 화면을 열었을 때 **When** 다국어 문구 목록 조회 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 목록 항목 선택 시 수정 모달 표시 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 저장 **Then** 그 결과가 화면에 반영된다.

## 6. 예외처리

| 발생 조건 | 사용자 안내 | 화면 처리 |
|---|---|---|
| 국문은 미입력으로 저장할 수 없습니다. 영문 미입력 시에는 국문으로 대체 표시되나 국문이 없으면 해당 영역이 표시되지 않습니다. | 무엇이 왜 막혔는지 그 자리에서 알린다 | 입력값과 스크롤 자리를 지킨 채 안내만 더한다 |
| 국문 미입력 시 확인 모달을 표시하지 않습니다. | 무엇이 왜 막혔는지 그 자리에서 알린다 | 입력값과 스크롤 자리를 지킨 채 안내만 더한다 |
| 저장 시 확인 모달을 표시합니다. 하나의 문구가 여러 화면에 동시에 반영됩니다. | 무엇이 왜 막혔는지 그 자리에서 알린다 | 입력값과 스크롤 자리를 지킨 채 안내만 더한다 |

## 7. 검증 규칙

- 국문이 미입력이면 저장하지 않습니다.

### 화면 정책

- 언어별로 화면을 분리하지 않습니다. 분리 시 미등록 항목을 육안으로 대조해야 합니다.
- 확인 모달은 수정 모달 위에 표시됩니다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.

### 향후 확장

- 영문 미등록 항목 필터.
