## 5. 사용자 시나리오

### 정상

- 조회 기간 필터 → 결과가 화면에 바로 반영된다.
- 주요 지표 6개 조회 → 결과가 화면에 바로 반영된다.
- 지역 분포 지도 및 표 조회 → 결과가 화면에 바로 반영된다.
- 지역 분포 집계 기준 필터 → 결과가 화면에 바로 반영된다.

### 인수 조건

- **Given** 이 화면을 열었을 때 **When** 조회 기간 필터 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 주요 지표 6개 조회 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 지역 분포 지도 및 표 조회 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 지역 분포 집계 기준 필터 **Then** 그 결과가 화면에 반영된다.

| 발생 조건 | 사용자 안내 | 화면 처리 |

| 등록 건수가 0인 지역도 지도와 표에 표시합니다. | 무엇이 왜 막혔는지 그 자리에서 알린다 | 입력값과 스크롤 자리를 지킨 채 안내만 더한다 |
| 강조 색상은 값이 0이 아닐 때 처리가 필요한 지표에만 적용합니다. | 무엇이 왜 막혔는지 그 자리에서 알린다 | 입력값과 스크롤 자리를 지킨 채 안내만 더한다 |

## 7. 검증 규칙

_N/A — 이 화면에는 해당되지 않습니다._

### 화면 정책

- 조회수 · 주가 · 예정 일정은 표시하지 않습니다. 각 항목에 전용 화면이 있어 중복 제공에 해당합니다.
- 방문 수는 표시하지 않습니다. 본 화면은 처리 대상 건수를 확인하는 화면이며 방문 통계는 통계 메뉴에서 제공합니다.
- 주요 지표 6개를 한 행에 배치합니다. 두 행으로 분리되면 항목 간 중요도가 다르게 인식됩니다.
- 날짜 직접 선택 기능을 제공하지 않습니다.
- 지도는 단계 구분도가 아닙니다. 색상은 지역 구분을 나타내며 건수는 표에서 확인합니다.
- 경계선 좌표 데이터(214KB)와 `d3-geo` 는 서버에서만 사용합니다. 클라이언트에는 경로 문자열 17개(약 3KB)만 전달합니다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.

### 향후 확장

- 지표 카드에서 해당 목록 화면으로 이동하는 링크.
