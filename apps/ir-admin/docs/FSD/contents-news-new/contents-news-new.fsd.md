## 5. 사용자 시나리오

### 정상

- 분류 및 제목 입력 → 결과가 화면에 바로 반영된다.
- 미리보기 패턴 입력 → 결과가 화면에 바로 반영된다.
- 노출 설정 → 결과가 화면에 바로 반영된다.
- 뉴스 등록 → 결과가 화면에 바로 반영된다.

### 인수 조건

- **Given** 이 화면을 열었을 때 **When** 분류 및 제목 입력 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 미리보기 패턴 입력 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 노출 설정 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 뉴스 등록 **Then** 그 결과가 화면에 반영된다.

## 7. 검증 규칙

- 분류와 제목은 공백만으로 저장할 수 없습니다.

### 화면 정책

- 선택한 패턴을 화면에서 즉시 표시합니다. 선택 시점과 고객 사이트 표시 결과가 일치해야 합니다.
- 패턴을 지정하지 않으면 목록의 항목이 시각적으로 구분되지 않습니다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.
