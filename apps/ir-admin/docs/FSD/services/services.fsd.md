- 이름으로 검색 → 결과가 화면에 바로 반영된다.

### 인수 조건

- **Given** 이 화면을 열었을 때 **When** 이름으로 검색 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 줄을 눌러 상세로 들어가기 **Then** 그 결과가 화면에 반영된다.

### 화면 정책

- 값의 모양은 제품과 같다(`Offering`). 다른 것은 여기 둘이 **파는 단위가 화면이 아니라 절차**라는 점이다 — 그래서 목록이 보여 주는 것도 상태가 아니라 몇 단계로 파는가다.
- 어드민 주소는 `/services` 인데 사이트에서는 SOLUTION 갈래에 선다. 어드민 주소는 무엇을 고치러 왔는지를, 사이트 주소는 찾아온 사람이 어느 갈래에서 찾는지를 말한다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.

### 향후 확장

- 서비스를 늘리는 자리 — 상세 화면을 함께 만들 때.
