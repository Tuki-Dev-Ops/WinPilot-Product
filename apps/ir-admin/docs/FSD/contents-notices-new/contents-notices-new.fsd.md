- 갈래 고르기 → 결과가 화면에 바로 반영된다.
- 제목·올린 날 넣기 → 결과가 화면에 바로 반영된다.
- 본문 적기 → 결과가 화면에 바로 반영된다.
- 고정과 노출 정하기 → 결과가 화면에 바로 반영된다.
- 등록 → 결과가 화면에 바로 반영된다.

## 7. 검증 규칙

- 갈래 · 제목 · 올린 날 · 내용은 공백만으로 둘 수 없다.

### 화면 정책

- 본문을 한 칸에 받고 빈 줄로 문단을 나눈다. 문단마다 칸을 두면 옮기고 지우는 단추가 따라붙어야 하고, 서너 문단짜리 공지에 그만한 장치는 과하다.
- 고정을 켜는 자리 옆에 무슨 일이 생기는지 적어 둔다 — 눌러 보면 아무 일도 일어나지 않고 결과는 사이트 목록의 차례에서만 드러난다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.
