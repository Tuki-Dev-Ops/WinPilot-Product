## 5. 사용자 시나리오

### 정상

- 상호 · 대표자 · 사업자등록번호 입력 → 결과가 화면에 바로 반영된다.
- 업태 및 업종 입력 → 결과가 화면에 바로 반영된다.
- 주소 · 전화번호 · 이메일 입력 → 결과가 화면에 바로 반영된다.
- 저장 → 결과가 화면에 바로 반영된다.

### 인수 조건

- **Given** 이 화면을 열었을 때 **When** 상호 · 대표자 · 사업자등록번호 입력 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 업태 및 업종 입력 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 주소 · 전화번호 · 이메일 입력 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 저장 **Then** 그 결과가 화면에 반영된다.

## 7. 검증 규칙

- 필수로 지정된 항목은 공백만으로 저장할 수 없습니다. 법령상 표시 의무 항목입니다.

### 화면 정책

- 회사 > 소개와 별도 화면으로 관리합니다. 회사 소개는 홍보 목적 콘텐츠이고 본 항목은 전자상거래법 · 정보통신망법상 표시 의무 항목입니다.
- 업태와 업종을 선택 항목으로 제공합니다. 자유 입력 시 동일 항목이 서로 다른 표기로 등록됩니다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.

### 향후 확장

- 사업자등록증 사본 첨부.
