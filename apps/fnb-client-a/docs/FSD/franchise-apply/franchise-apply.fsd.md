## 7. 검증 규칙

- 성명이 미입력이면 성명 입력을 요청하는 메시지를 표시합니다.
- 연락처는 미입력과 형식 오류를 구분하여 각각의 메시지를 표시합니다.
- 지역과 예산을 선택하지 않으면 접수하지 않습니다.
- 개인정보 수집 · 이용에 동의하지 않으면 접수하지 않습니다.
- 검증 결과는 신청 버튼을 선택한 이후에 표시합니다.

### 화면 정책

- 필수 입력 항목은 4개로 제한합니다.
- 예산은 구간 선택으로 수집합니다.
- 지역 목록은 가맹점 데이터와 동일한 기준을 사용합니다.
- 지역과 예산의 초기값을 미선택 상태로 유지합니다.
- 문의 내용은 선택 항목입니다.
- 프론트엔드 전용 화면입니다. 접수된 신청은 본 화면에만 반영됩니다.

## 8. 화면 상태

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.
