## 5. 사용자 시나리오

### 정상

- 마케팅 채널 필터 → 결과가 화면에 바로 반영된다.
- 채널별 게시물 목록 조회 → 결과가 화면에 바로 반영된다.

### 인수 조건

- **Given** 이 화면을 열었을 때 **When** 마케팅 채널 필터 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 채널별 게시물 목록 조회 **Then** 그 결과가 화면에 반영된다.

## 7. 검증 규칙

_N/A — 이 화면에는 해당되지 않습니다._

### 화면 정책

- 실제 운영 중인 채널만 등록합니다.
- 채널 필터에는 채널명만 표시하고 계정명은 표시하지 않습니다. 이동할 수 없는 링크로 오인될 수 있기 때문입니다.
- 게시일을 항상 표시합니다. 마케팅 채널에서는 최신 게시물 유무가 우선 판단 기준입니다.
- 채널 필터에는 게시물 수를 표시하지 않습니다.
- 페이지 하단에 별도 상담 영역을 배치하지 않습니다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.

### 향후 확장

- 채널 계정 URL 등록. 등록 시 카드에 링크를 연결하고 필터에 계정명을 함께 표시합니다.
- 게시물 이미지 등록. 현재는 대체 이미지 영역으로 표시합니다.
