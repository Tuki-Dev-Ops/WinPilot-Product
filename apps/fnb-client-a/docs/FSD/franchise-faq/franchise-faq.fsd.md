## 5. 사용자 시나리오

### 정상

- 상담 전화번호 조회 → 결과가 화면에 바로 반영된다.
- 질문 분류 필터 → 결과가 화면에 바로 반영된다.
- 질문 항목 선택 시 답변 표시 → 결과가 화면에 바로 반영된다.
- 가맹 상담 신청 페이지로 이동 → 결과가 화면에 바로 반영된다.

### 인수 조건

- **Given** 이 화면을 열었을 때 **When** 상담 전화번호 조회 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 질문 분류 필터 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 질문 항목 선택 시 답변 표시 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 가맹 상담 신청 페이지로 이동 **Then** 그 결과가 화면에 반영된다.

### 화면 정책

- 기본 선택값은 전체입니다.
- 분류는 자유 입력이 아닌 사전 정의된 목록에서 선택합니다.
- 분류 정렬은 문의 빈도 순으로 고정합니다. 등록 순으로 정렬하면 질문 등록 시마다 순서가 변경됩니다.
- 분류 필터는 좌측에 배치합니다. 상단에 탭 내비게이션이 이미 존재하여 가로 요소가 중복되기 때문입니다.
- 아코디언 동작은 공지사항 · 고객센터 FAQ 와 공통 컴포넌트를 사용합니다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|

- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
