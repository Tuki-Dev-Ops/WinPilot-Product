## 5. 사용자 시나리오

### 정상

- 메뉴 카테고리 필터 → 결과가 화면에 바로 반영된다.
- 메뉴 카드 선택 시 상세 페이지로 이동 → 결과가 화면에 바로 반영된다.

### 인수 조건

### 화면 정책

- 카테고리 정렬은 관리자에 등록된 순서를 따르며, 카테고리 내 메뉴는 등록 순서를 따릅니다.
- 선택한 카테고리는 URL 파라미터로 유지하지 않습니다. 단일 페이지 내 조회 조건이므로 공유 대상이 아닙니다.
- 표시 가격은 부가세 포함 금액입니다.
- 비노출 메뉴는 데이터는 유지되며 고객 화면에서만 제외됩니다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.

### 향후 확장

- 메뉴 이미지 등록. 현재는 대체 이미지 영역으로 표시합니다.
- 알레르기 유발 재료 기준 필터. 현재는 상세 페이지에서 개별 확인합니다.
