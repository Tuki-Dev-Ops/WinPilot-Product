## 5. 사용자 시나리오

### 정상

- 메인 배너에서 메뉴 목록 또는 매장 찾기로 이동 → 결과가 화면에 바로 반영된다.
- 공지 요약 영역에서 공지사항 목록으로 이동 → 결과가 화면에 바로 반영된다.
- 대표 메뉴 슬라이드에서 메뉴 상세로 이동 → 결과가 화면에 바로 반영된다.
- 신규 오픈 매장 슬라이드 조회 → 결과가 화면에 바로 반영된다.
- 가맹점 실적 영역에서 창업 안내로 이동 → 결과가 화면에 바로 반영된다.

### 인수 조건

- **Given** 이 화면을 열었을 때 **When** 메인 배너에서 메뉴 목록 또는 매장 찾기로 이동 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 공지 요약 영역에서 공지사항 목록으로 이동 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 대표 메뉴 슬라이드에서 메뉴 상세로 이동 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 신규 오픈 매장 슬라이드 조회 **Then** 그 결과가 화면에 반영된다.

### 화면 정책

- 공지 정렬 순서는 공유 데이터에서 결정합니다(상단 고정 우선, 이후 등록일 역순). 홈의 공지 요약과 공지사항 목록이 동일한 순서를 사용합니다.
- 대표 메뉴 슬라이드는 태그가 등록된 메뉴를 앞에 배치하되 전체 메뉴를 모두 포함합니다.
- 신규 오픈 매장은 최대 5건까지 표시합니다.
- 주요 지표 3개 항목은 고정값이 아니라 공유 데이터에서 집계합니다.
- 가맹점 실적 영역의 수치는 예시값입니다. 실제 수치로 교체할 경우 정보공개서 및 예상매출액 산정서와 동일한 값을 사용해야 합니다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.

### 향후 확장

- 메인 배너 이미지 연동. 관리자에 데이터(`FNB_BANNERS`)는 있으나 홈에서 아직 사용하지 않습니다.
- 팝업 연동. 동일한 사유로 영역만 정의되어 있습니다.
- 브랜드 이미지 적용. 현재는 타이포그래피와 배경 패턴으로 구성합니다.
