### 화면 정책

- 비용이 절차보다 앞이다. 창업 검토에서 가장 먼저 나오는 물음이 그것이다.
- 인테리어 줄은 평당 단가에서 나온다 — 인테리어 화면의 기본형과 같은 값이어야 한다.
- 합계는 화면에서 세지 않고 store 가 센다. 화면마다 세면 화면 수만큼 다른 합계가 생긴다.
- 절차에 걸리는 기간을 함께 적는다. 절차만 적으면 그래서 몇 달 걸리나가 그대로 전화 문의로 남는다.
- 자주 묻는 것은 옆 탭으로 뺐다 — 다시 온 사람이 비용 표와 절차를 두 번 지나지 않게.
- 번호를 붙이는 상담 판은 이 화면 하나다. 다섯 화면에 다 붙이면 푸터의 창구 둘과 섞인다.

## 8. 화면 상태

| 상태 | 화면 |

| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.
