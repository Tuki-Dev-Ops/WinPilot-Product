## 5. 사용자 시나리오

### 정상

- 공지사항 페이지로 이동 → 결과가 화면에 바로 반영된다.
- 질문 항목 선택 시 답변 표시 → 결과가 화면에 바로 반영된다.

### 인수 조건

- **Given** 이 화면을 열었을 때 **When** 공지사항 페이지로 이동 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 질문 항목 선택 시 답변 표시 **Then** 그 결과가 화면에 반영된다.

## 7. 검증 규칙

_N/A — 이 화면에는 해당되지 않습니다._

### 화면 정책

- 매장 이용 고객 대상 질문만 표시합니다. 창업 관련 질문은 창업 안내 하위에 별도 화면이 있습니다.
- 대상 구분 필터를 제공하지 않습니다.
- 분류 필터를 제공하지 않습니다. 등록 건수가 적어 필터 추가 시 조작 단계만 증가합니다.
- 아코디언 동작은 공지사항 · 창업 개설문의와 공통 컴포넌트를 사용합니다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.

### 향후 확장

- 질문 검색.
- 분류 필터. 등록 건수 증가 시 도입합니다.
