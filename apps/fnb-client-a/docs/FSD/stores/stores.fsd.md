## 5. 사용자 시나리오

### 정상

- 매장명 및 주소 검색 → 결과가 화면에 바로 반영된다.
- 지역 필터 → 결과가 화면에 바로 반영된다.
- 목록 항목 선택 시 지도 이동 → 결과가 화면에 바로 반영된다.
- 지도 마커 선택 시 해당 매장 정보 조회 → 결과가 화면에 바로 반영된다.
- 검색 조건 초기화 → 결과가 화면에 바로 반영된다.

### 인수 조건

- **Given** 이 화면을 열었을 때 **When** 매장명 및 주소 검색 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 지역 필터 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 목록 항목 선택 시 지도 이동 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 지도 마커 선택 시 해당 매장 정보 조회 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 검색 조건 초기화 **Then** 그 결과가 화면에 반영된다.

## 7. 검증 규칙

_N/A — 이 화면에는 해당되지 않습니다._

### 화면 정책

- 검색 조건과 지도가 연동됩니다. 목록이 필터링되면 지도 표시 범위도 함께 조정됩니다.
- 선택한 매장이 없으면 현재 목록의 전체 매장이 표시되도록 지도 범위를 조정합니다.
- 검색 조건 초기화 버튼은 검색 조건이 적용된 경우에만 표시합니다.
- 지역 목록은 가맹점 데이터에서 도출합니다. 별도 관리 시 신규 지역의 매장이 필터에 포함되지 않습니다.
- 좌표는 가맹점 데이터에 포함하여 관리합니다. 화면에서 주소를 좌표로 변환하면 매장 수만큼 외부 요청이 발생합니다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.
