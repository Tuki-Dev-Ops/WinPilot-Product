## 5. 사용자 시나리오

### 정상

- 알레르기 유발 재료 조회 → 결과가 화면에 바로 반영된다.
- 열량 조회 → 결과가 화면에 바로 반영된다.
- 동일 카테고리 추천 메뉴로 이동 → 결과가 화면에 바로 반영된다.
- 메뉴 목록으로 이동 → 결과가 화면에 바로 반영된다.

### 인수 조건

- **Given** 이 화면을 열었을 때 **When** 알레르기 유발 재료 조회 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 열량 조회 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 동일 카테고리 추천 메뉴로 이동 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 메뉴 목록으로 이동 **Then** 그 결과가 화면에 반영된다.

### 화면 정책

- 사전 생성 경로는 판매 중인 메뉴만 대상으로 합니다. 비노출 메뉴까지 생성하면 검색 엔진에 노출됩니다.
- 알레르기 유발 재료가 없는 경우 빈 값이 아니라 「해당 없음」으로 표시합니다.
- 알레르기 정보에 조리 기구 공용 사용 안내를 항상 함께 표시합니다.
- 판매 중지 안내는 가격과 설명보다 상단에 배치합니다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.

### 향후 확장

- 메뉴 이미지 다중 등록.
- 매장별 판매 여부. 현재는 브랜드 공통 값만 관리합니다.
