## 5. 사용자 시나리오

### 정상

- 신청자 · 연락처 · 문의 내용 검색 → 결과가 화면에 바로 반영된다.
- 처리 상태 및 지역 필터 → 결과가 화면에 바로 반영된다.
- 목록 항목 선택 시 상세 페이지로 이동 → 결과가 화면에 바로 반영된다.

### 인수 조건

- **Given** 이 화면을 열었을 때 **When** 신청자 · 연락처 · 문의 내용 검색 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 처리 상태 및 지역 필터 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 목록 항목 선택 시 상세 페이지로 이동 **Then** 그 결과가 화면에 반영된다.

### 화면 정책

- 접수 상태에만 강조 색상을 적용합니다. 상담중 건까지 강조하면 미처리 건과 진행 건이 구분되지 않습니다.
- 보류 상태는 회색으로 표시하되 완료 상태와 구분합니다.
- 미처리 건수 집계는 대시보드에서 수행합니다.
- 체크박스 열은 삭제 기능이 없는 화면에도 배치합니다. 표별 첫 번째 열 위치를 통일하기 위한 것입니다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.
