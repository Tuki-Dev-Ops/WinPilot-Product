- 제목·본문으로 검색 → 결과가 화면에 바로 반영된다.
- 상태로 거르기 → 결과가 화면에 바로 반영된다.
- 줄을 눌러 상세로 들어가기 → 결과가 화면에 바로 반영된다.
- 공지 등록 → 결과가 화면에 바로 반영된다.
- 삭제 → 결과가 화면에 바로 반영된다.

### 인수 조건

- **Given** 이 화면을 열었을 때 **When** 제목·본문으로 검색 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 상태로 거르기 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 줄을 눌러 상세로 들어가기 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 공지 등록 **Then** 그 결과가 화면에 반영된다.

### 화면 정책

- 본문을 목록에 세운다. 제목만 세우면 무엇을 알린 글인지 열어 봐야 안다 — 이 브랜드의 공지는 값 조정 · 개점 · 휴점처럼 한 줄로 요약되는 것들이다.
- 고정을 열로 세운다. 고정한 글이 둘 이상인 것은 목록에서 세어야 보인다.
- 차례는 store 가 정한다 — 사이트 공지 목록과 같은 차례여야 한다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.
