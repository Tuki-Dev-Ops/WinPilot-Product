# 관리자 연동 — 본 사이트가 조회하는 데이터의 출처

본 사이트에는 서버가 없습니다. 관리자에서 저장한 값이 본 사이트에 반영되는 것은 두 앱이
**동일한 모듈을 조회**하기 때문이며 통신에 의한 것이 아닙니다.

```mermaid
flowchart LR
  A[IR Admin · 3303] -->|저장| S[(packages/store · ir.ts · site.ts)]
  S -->|조회| C[IR Client · 3304]
```

## 본 사이트의 특성

쇼핑몰과 브랜드 사이트는 구매자를 대상으로 하고, 본 사이트는 투자자와 주주를 대상으로 합니다.
본 사이트의 정보 오류는 구매 오류가 아니라 **공시 위반**에 해당합니다.

따라서 본 문서는 수정 가능한 항목뿐 아니라 **수정할 수 없는 항목**과 **사이트에 반영되지
않는 항목**을 동일한 비중으로 기재합니다. 실제와 다른 대응표는 수정 대상 확인을 어렵게 합니다.

---

## 1. 관리자에서 수정하면 사이트에 반영되는 항목

| 사이트 화면 | 조회 데이터 | 관리 화면 |
|---|---|---|
| 전 화면 — 팝업 | `liveSitePopups()` | 배너 > 팝업 |
| 회사 소개 · 연혁 | `MILESTONES` | 회사 > 연혁 |
| 회사 소개 · 특허 및 인증 | `publicCredentials()` | 회사 > 특허 및 인증 |
| 제품 (`/products`) | `publicSolutions()` · `SITE_SERVICES` · `SERVICE_DETAILS` | 제품 > 목록 · 서비스 > 목록 · `/solutions` † |
| 솔루션 상세 6개 | `findOffering()` | 제품 > 목록 · 서비스 > 목록 |
| 고객지원 — 공지사항 | `publicSiteNotices()` · `SITE_NOTICE_GROUPS` | 콘텐츠 > 공지사항 |
| 고객지원 — 뉴스 | `publicMediaClips()` | 콘텐츠 > 뉴스 |
| 고객지원 — FAQ | `publicSiteFaqs()` · `FAQ_GROUPS` | 콘텐츠 > FAQ |
| 고객지원 — 문의하기 | `SITE_INQUIRY_KINDS` · `SITE_REGIONS` | 문의 > 설정 |

7개 자원입니다. **나머지 항목은 아래 두 표에 있습니다.**

† 표시 항목은 **관리자 사이드바에 없는 화면**입니다. URL 로 직접 접근해야 합니다
(`apps/ir-admin/docs/path.md` §5).

**공시는 본 표에서 제외되었습니다.** 관리자의 공시 · 재무 · 주주 · 자료 화면 10개를
삭제하였으므로 공시 게시 상태를 변경하는 화면이 저장소에 없습니다.

---

## 2. 사이트에 노출되나 관리자에서 수정할 수 없는 항목

본 한 쌍의 주요 미구현 항목입니다.

**관리자의 공시 · 재무 · 주주 · 자료 화면 10개를 삭제하면서 해당 데이터가 모두 본 항목으로
이동하였습니다.**

| 데이터 | 사이트 노출 위치 | 관리자 |
|---|---|---|
| `IR_COMPANY` 전체 | **전 화면의 푸터** · 회사 소개 · 오시는 길 | 최초부터 화면 없음 |
| `DISCLOSURES` | 공시 목록 · 공시 상세 | **화면 삭제** |
| `FINANCIALS` · `DIVIDENDS` · `STOCK` | 재무정보 · 배당정보 · 주가정보 | 동일 |
| `MEETINGS` | 주주총회 · 전자투표 | 동일 |
| `OFFICERS` · `SHAREHOLDERS` | 지배구조 | 동일 |
| `IR_DOCUMENTS` · `IR_SCHEDULES` | 자료실 · IR 일정 | 동일 |
| `SUBSCRIBERS` | 알림 신청 | 동일 |
| `DIRECTIONS` | 오시는 길 | 최초부터 화면 없음 |
| `HERO_SLIDES` | 홈 메인 배너 | 최초부터 화면 없음 — 배너 > 메인 비주얼과 **연동되어 있지 않음**(§4) |
| `SUPPORT_CATEGORIES` | 알림 신청 | 최초부터 화면 없음 |

`IR_COMPANY` 를 최상단에 배치한 사유는 **전 화면의 푸터가 해당 값을 표시**하기 때문입니다.
대표이사 변경 시 수정할 화면이 관리자에 없으며, 저장소 내에서 이미 `SITE_SUPPLIER.ceo` 와
값이 불일치합니다.

삭제한 10개 화면은 **목록 조회만 제공하고 등록 기능이 없는** 조회 전용 화면이었습니다.
따라서 본 표의 변경 사항은 「수정 불가」가 「조회 불가」가 된 것입니다. 해당 화면을 사이트에서도
제외하기로 결정하는 시점에 `ir.ts` 를 함께 삭제합니다.

## 3. 관리자에만 있고 사이트에 반영되지 않는 항목

저장은 처리되나 사이트에 반영되지 않는 항목입니다.

| 데이터 | 관리 화면 |
|---|---|
| `SITE_SEO` | 설정 > SEO 정보 |
| `SITE_SUPPLIER` | 설정 > 공급자 정보 |
| `LEGAL_DOCS` | 설정 > 이용약관 · 개인정보 처리방침 |
| `SITE_INTRO` | 회사 > 소개 |
| `LOCALE_PAIRS` | 설정 > 국문 · 영문 |
| `PAGE_VISITS` · `VISIT_TREND` | 통계 3개 (조회 전용이므로 정상) |

`LEGAL_DOCS` 는 확인이 필요한 항목입니다. 사이트의 `/terms` 와 `/privacy` 는 화면에서 관리하는
내용을 표시하고 관리자는 별도 원문을 관리합니다. **동일 문서가 두 곳에서 관리되므로 게시 중인
약관을 화면에서 확인할 수 없습니다.**

## 4. 조회 단계에서 제외되는 항목

사이트에서 별도로 판단하지 않습니다. store 의 공개 필터가 일괄 처리합니다.

| 필터 | 제외 대상 |
|---|---|
| `publicDisclosures()` | `작성 중` · `검토 요청`. **`공시됨` 과 `정정` 만 조회** |
| `publicSiteNotices()` | 비공개 공지. 상단 고정 항목 우선 배치 |
| `publicMediaClips()` | 비공개 뉴스 |
| `publicSiteFaqs()` | 비공개 FAQ |
| `publicCredentials()` | 비공개 특허 · 인증 |
| `publicSolutions()` | 비노출 제품 |
| `liveSitePopups()` | 게시 기간 이전 또는 종료 · 비노출 설정 항목 |

공시는 **URL 로 직접 접근해도 표시하지 않습니다.** 다른 자원은 상세 URL 접근을 허용하나
공시는 제한합니다. 미공시 정보가 URL 로 조회되면 미공개 정보 유출에 해당합니다.

## 5. 팝업 노출 규칙

`scheduleState()` 가 **게시 기간을 기준으로** 판정합니다. B2C 배너와 **동일한 함수**를
사용합니다. 동일한 판정을 두 곳에서 구현하면 자정 전후의 산출 결과가 달라질 수 있습니다.

| 상태 | 정의 |
|---|---|
| `노출 중` | 현재 게시 중. `liveSitePopups()` 가 해당 항목만 전달 |
| `예정` | 시작일 이전 |
| `종료` | 종료일 경과 |
| `숨김` | 운영자가 비노출로 설정. 게시 기간과 무관 |

- 팝업은 **한 번에 하나만** 표시합니다. 닫으면 다음 항목을 표시합니다.
- 표시 위치는 **화면 중앙 1개**입니다. 휴무와 처리방침 개정 등 확인이 필요한 안내만 게시하므로
  화면 모서리에 배치하면 열람률이 저하됩니다.
- **본문이 필수**입니다. 제목만 표시되는 팝업은 안내 내용을 전달할 수 없습니다.
- `오늘 하루 보지 않기` 설정은 **사용자 브라우저에만** 저장됩니다. 관리자에서 조회할 수 없습니다.

**메인 배너는 아직 연동되어 있지 않습니다.** 관리자의 배너 > 메인 비주얼이 데이터를 관리하고
있으나 사이트는 `HERO_SLIDES` 를 표시합니다. 팝업만 연동되어 있습니다.

## 6. 주가 직접 입력 기능 미제공 사유

주가 입력 항목을 제공하지 않는 것은 **의도된 설계**입니다. 직접 입력을 허용하면 입력 오류가
투자자 화면의 시세로 표시되며, 이를 정정하는 것은 정정 공시 대상이 됩니다. 사이트는 **지연
시세임을 항상 표시**합니다.

`FINANCIALS` 와 `MEETINGS` 등에 관리 화면이 없는 것은 이와 다른 사유입니다. 해당 항목은
**미구현 상태**이며 현재는 목록 화면도 삭제된 상태입니다.
