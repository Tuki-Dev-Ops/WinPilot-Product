- 클라우드 제품 목록 조회 → 결과가 화면에 바로 반영된다.
- 제품 상세 페이지로 이동 → 결과가 화면에 바로 반영된다.
- 서비스 상세 페이지로 이동 → 결과가 화면에 바로 반영된다.
- 문의하기 페이지로 이동 → 결과가 화면에 바로 반영된다.

### 인수 조건

- **Given** 이 화면을 열었을 때 **When** 클라우드 제품 목록 조회 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 제품 상세 페이지로 이동 **Then** 그 결과가 화면에 반영된다.

### 화면 정책

- 제품과 서비스를 제공 방식에 따라 구분하여 표시합니다. 클라우드 제품은 계약 즉시 사용하는 형태이고 서비스는 인력이 수행하는 형태입니다.
- 서비스 여부는 명칭이 아닌 데이터 속성으로 판단합니다. 명칭 기준으로 처리하면 서비스가 추가될 때 목록에서 누락됩니다.
- 클라우드 제품에만 이미지를 표시합니다.
- 주요 기능은 기능명 4개만 표시합니다.
- 이미지는 카드 상단에 가로로 배치합니다. 세로 배치 시 목록 길이가 두 배가 됩니다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.
