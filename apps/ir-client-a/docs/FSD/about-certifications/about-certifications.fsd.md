## 7. 검증 규칙

_N/A — 이 화면에는 해당되지 않습니다._

### 화면 정책

- 등록번호를 필수 항목으로 관리합니다. 외부에서 조회 가능한 값이므로 등록번호가 없으면 정보의 활용도가 없습니다.
- 검색 대상에 등록번호를 포함합니다.
- 구분별 건수는 필터 적용 전 전체 건수를 기준으로 표시합니다.
- 필터 적용 후 검색 결과 건수를 표시합니다. 표시하지 않으면 조회 결과가 없는 사유를 구분할 수 없습니다.
- 정렬은 공유 데이터에서 제공하는 순서를 그대로 사용합니다.
- 페이지네이션을 적용하지 않습니다. 필터와 검색이 클라이언트에서 처리되므로 추가 요청이 발생하지 않습니다.

- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
