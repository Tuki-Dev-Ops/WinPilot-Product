## 7. 검증 규칙

_N/A — 이 화면에는 해당되지 않습니다._

### 화면 정책

- 상단 고정 항목을 우선 배치하고 그 안에서 게시일 역순으로 정렬합니다.
- 상단 고정 여부를 배지로 표시합니다. 표시 없이 순서만 조정하면 정렬 기준을 확인할 수 없습니다.
- 최상단 1건은 본문이 펼쳐진 상태로 진입합니다.
- 상세 페이지를 제공하지 않습니다. 개별 공지의 고유 URL 이 없다는 제약을 감수합니다.
- 분류별 건수는 필터 적용 전 전체 건수를 기준으로 표시합니다.
- 페이지네이션을 적용하지 않습니다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.

### 향후 확장

- 공지 상세 페이지 및 개별 URL.
- 첨부파일.
- 선택한 분류와 검색어를 URL 파라미터로 유지. 현재는 새로고침 시 초기화됩니다.
