## 5. 사용자 시나리오

### 정상

- 본사 주소 조회 → 결과가 화면에 바로 반영된다.
- 대표 전화번호 조회 → 결과가 화면에 바로 반영된다.
- 지하철 · 버스 · 자가용 경로 안내 조회 → 결과가 화면에 바로 반영된다.
- 방문 절차 안내 조회 → 결과가 화면에 바로 반영된다.

### 인수 조건

- **Given** 이 화면을 열었을 때 **When** 본사 주소 조회 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 대표 전화번호 조회 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 지하철 · 버스 · 자가용 경로 안내 조회 **Then** 그 결과가 화면에 반영된다.

_N/A — 이 화면에는 해당되지 않습니다._

### 화면 정책

- 주소를 가장 크게 표시합니다. 방문자가 주소를 지도 앱에 입력하는 것이 주된 이용 방식입니다.
- 경로별로 다른 아이콘을 사용합니다.
- 고객센터 하위 다른 화면과 달리 분류 필터와 검색을 제공하지 않습니다. 항목이 3개이므로 조작 단계만 증가합니다.
- 표시 순서는 지하철 · 버스 · 자가용입니다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.

### 향후 확장

- 주소 복사 버튼과 지도 앱 연결.
- 전화 걸기 링크.
- 층 · 호수 정보와 주차 등록 절차.
