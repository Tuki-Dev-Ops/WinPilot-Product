## 5. 사용자 시나리오

### 정상

- 회사 비전 조회 → 결과가 화면에 바로 반영된다.
- 주요 사업 조회 → 결과가 화면에 바로 반영된다.
- 주요 사업 영역에서 해당 제품 상세 페이지로 이동 → 결과가 화면에 바로 반영된다.
- 사업 영역의 제품 카드 선택 시 상세 페이지로 이동 → 결과가 화면에 바로 반영된다.

### 인수 조건

- **Given** 이 화면을 열었을 때 **When** 회사 비전 조회 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 주요 사업 조회 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 주요 사업 영역에서 해당 제품 상세 페이지로 이동 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 사업 영역의 제품 카드 선택 시 상세 페이지로 이동 **Then** 그 결과가 화면에 반영된다.

### 화면 정책

- 회사 현황 수치는 등록된 데이터에서 집계합니다. 연혁 건수와 특허 · 인증 건수는 공개 항목만 집계하여 각 목록 화면과 동일한 값을 표시합니다.
- 항목명을 값보다 상단에 배치합니다.
- 설립 정보는 연도 단위로 표시합니다.
- 페이지 하단의 연혁 · 특허 및 인증 이동 링크는 제공하지 않습니다. 상단 내비게이션에서 동일한 경로를 제공합니다.
- 사업자 정보 표의 항목 순서를 고정합니다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |
