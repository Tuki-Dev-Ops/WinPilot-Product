## 7. 검증 규칙

_N/A — 이 화면에는 해당되지 않습니다._

### 화면 정책

- 검색 대상에 답변 본문을 포함합니다. 질문 문구와 사용자가 입력하는 검색어가 다른 경우가 있습니다.
- 공지사항과 동일한 아코디언 컴포넌트를 사용합니다. 브라우저 기본 요소를 사용하면 행 높이와 여백이 달라집니다.
- 펼침 상태를 스크린 리더에 전달하고 키보드 조작을 지원합니다. 닫힌 답변이 브라우저 찾기 대상에서 제외되는 제약은 답변까지 검색하는 검색 기능으로 보완합니다.
- 답변은 한 번에 하나만 표시합니다.
- 최상단 1건은 답변이 펼쳐진 상태로 진입합니다.
- 분류는 사전 정의된 항목을 사용합니다. 등록 건수가 0인 분류를 목록에서 제외하면 해당 분류가 없는 것으로 인식됩니다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.

### 향후 확장

- 데이터 없음 안내에서 문의하기 페이지로 이동하는 링크.
- 답변 도움 여부 응답 수집.
- 질문별 고유 URL.
