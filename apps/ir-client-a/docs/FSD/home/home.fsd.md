### 화면 정책

- 본 화면은 IR 데이터를 조회하지 않습니다. 공시 · 재무 · 주가 · 일정은 각 화면에서 전체 목록으로 제공합니다.
- 메인 배너 슬라이드는 3개로 고정합니다.
- 슬라이드 전환 간격은 7초입니다.
- 사업 구조 영역은 자동 전환하지 않습니다. 메인 배너가 자동 전환 중이므로 동시 전환 시 가독성이 저하됩니다.
- 사업 구조 영역에서 항목을 선택하면 배치는 유지하고 선택 표시만 변경합니다.
- 제품 카드의 이동 경로는 카드에서 정의하지 않고 제품 데이터에서 조회합니다(`siteServiceHref`).
- 저작권 연도는 데이터로 관리합니다. 현재 시각에서 산출하면 사전 생성 페이지에서 빌드 시점 값으로 고정됩니다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.

### 향후 확장

- 메인 배너를 관리자 데이터(`SITE_BANNERS`)와 연동. 현재는 슬라이드 3개를 화면에서 관리합니다.
- 배경 영상 파일 적용. 현재는 영역별 배경 패턴과 재생 아이콘으로 대체합니다.
- IR 메뉴 진입 경로. 현재 사이트 내에 IR 화면으로 진입하는 링크가 없습니다.
