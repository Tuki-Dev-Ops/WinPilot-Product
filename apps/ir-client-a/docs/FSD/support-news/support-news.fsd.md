## 5. 사용자 시나리오

### 정상

- 뉴스 분류 필터 → 결과가 화면에 바로 반영된다.
- 제목 및 분류 검색 → 결과가 화면에 바로 반영된다.
- 뉴스 목록 조회 → 결과가 화면에 바로 반영된다.

### 인수 조건

- **Given** 이 화면을 열었을 때 **When** 뉴스 분류 필터 **Then** 그 결과가 화면에 반영된다.
- **Given** 이 화면을 열었을 때 **When** 제목 및 분류 검색 **Then** 그 결과가 화면에 반영된다.

## 7. 검증 규칙

_N/A — 이 화면에는 해당되지 않습니다._

### 화면 정책

- 검색 결과를 카드 형태로 표시합니다. 영상 자료는 제목보다 이미지로 식별합니다.
- 분류를 등록 데이터에서 도출합니다. 사전 정의 방식으로 관리하면 신규 분류의 항목이 필터에 포함되지 않습니다.
- 분류 정렬은 등록 순서를 따릅니다.
- 메인 페이지 미디어 영역과 동일한 이미지 패턴을 사용합니다.
- 메인 페이지에서는 최신 5건을 노출하고 본 화면에서는 전체를 표시합니다.

## 8. 화면 상태

| 상태 | 화면 |
|---|---|
| 최초 | 값이 오기 전의 자리(뼈대)를 그려 둔다 — 자리를 비우면 화면이 튄다 |
| 불러온 뒤 | 정상 화면 |
| 비어 있음 | 목록 자리를 비우지 않고 왜 비었는지 한 줄로 알린다 |
| 오류 | 같은 자리에 안내와 다시 시도할 길을 둔다 |

### UX 정책

- 조건을 채우지 못한 단추는 **잠근다.** 눌러 놓고 다음 화면에서 막으면 무엇이 잘못됐는지 늦게 안다.
- 알림은 화면 하단 정중앙 토스트 한 곳에서만 띄운다.
- 되돌릴 수 없는 일(삭제·취소)은 확인을 한 번 묻는다.
- 키보드만으로 모든 요소에 닿을 수 있고, 포커스가 어디 있는지 눈에 보인다.
- ESC 로 열린 것(모달·서랍)을 닫는다.

### 향후 확장

- 영상 파일 재생. 현재 데이터에 영상 URL 항목이 없습니다.
- 게시일 표시. 현재는 분류와 제목만 관리합니다.
- 뉴스 상세 페이지.
