# 솔루션 카드 사진

홈 화면의 `Solution` 칸(`app/_components/HomeSolutions.tsx`)이 쓰는 사진이다.

## 어디서 왔고, 써도 되는가

전부 [Pexels](https://www.pexels.com/license/) 다. 그 라이선스는 **상업적 사용을 허용하고 출처
표기를 요구하지 않는다.** 그래도 여기 적어 두는 이유는 나중에 "이 사진 어디서 났나" 를 물을
사람이 반드시 생기기 때문이다 — 그때 원본을 찾을 수 없으면 사진을 통째로 갈아야 한다.

| 파일 | Pexels ID | 무엇이 찍혔나 | 어느 솔루션 |
|---|---|---|---|
| `mes.jpg` | 16544056 | 협동로봇 팔 클로즈업 | Cloud MES |
| `erp.jpg` | 4277794 | 창고 랙 통로와 팔레트 | Cloud ERP |
| `crm.jpg` | 5453828 | 헤드셋을 쓴 상담석 | Cloud CRM |
| `dxp.jpg` | 27141314 | 어두운 화면 위의 조작 패널 | Cloud DXP |

원본 주소는 `https://www.pexels.com/photo/{ID}/` 이고, 내려받은 주소는 이 모양이다:

```
https://images.pexels.com/photos/{ID}/pexels-photo-{ID}.jpeg?auto=compress&cs=tinysrgb&w=900&h=1200&fit=crop
```

`w=900&h=1200&fit=crop` 을 붙이는 이유: 카드가 세로로 긴 모양이라, 가로 사진을 그대로 받아
화면에서 자르면 **900×1200 만 보여 주려고 1920×1280 을 내려받는** 일이 된다. 받을 때 잘라 오면
파일이 3분의 1로 준다.

## 고를 때 걸렀던 것

**남의 회사 이름이 찍힌 사진.** 처음 고른 MES 사진(Pexels 32845700)은 작업자 점퍼에 실제
제철사 로고가 크게 박혀 있었다. 라이선스는 문제가 없지만 **우리 홈페이지에 그 회사 로고가
실리면 고객사로 읽힌다.** 있지도 않은 거래 관계를 그림 하나가 만들어 내는 셈이다.

그래서 고르는 기준이 하나 더 있다 — **읽히는 상표가 없을 것.** 설비 제조사 이름이 기계에
작게 새겨진 정도는 넘어가지만, 사람이 입은 옷이나 간판에 붙은 것은 쓰지 않는다.

## 바꾸려면

같은 이름으로 파일만 덮어쓰면 된다(`mes.jpg` · `erp.jpg` · `crm.jpg` · `dxp.jpg`). 화면 쪽 코드는 파일
이름을 솔루션 `id` 로 만들어 쓰므로 고칠 것이 없다. 대신 **이 표를 같이 고쳐야 한다.**
