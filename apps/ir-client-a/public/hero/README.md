# 첫 화면 배경 영상과 화면 머리 배너

## 첫 화면 배경 영상 — `factory.mp4`

| | |
|---|---|
| 무엇 | Industrial Robot Arm in High-Tech Factory |
| 출처 | [Pexels #32386532](https://www.pexels.com/video/industrial-robot-arm-in-high-tech-factory-32386532/) |
| 라이선스 | [Pexels License](https://www.pexels.com/license/) — 상업적 사용 가능, 출처 표기 의무 없음 |
| 파일 | 1280×720 · 2.4MB |

**4K(3840×2160, 18MB)가 아니라 720p 를 받았다.** 이 영상은 흐리게 눌러 배경으로 까는 것이라
화질이 올라가도 화면에서 달라지는 것이 없고, 첫 화면이 뜨는 시간만 여덟 배 늘어난다.

내려받는 주소는 `https://www.pexels.com/download/video/{id}/?w=1280` 이다 — 파라미터 없이
받으면 원본(4K)이 온다.

`HomeHero` 는 **영상 없이도 뜬다.** 기본 배경은 인라인 SVG 로 그린 빛줄기이고, 영상은
`videoSrc` 를 넘길 때만 그 위에 깔린다.

`line.mp4` · `robotics.mp4` 는 같은 자리에 쓸 수 있는 예비다.

## 화면 머리 배너 — 화면마다 한 장

`PageHero` 가 화면 위에 까는 사진이다. 화면 쪽에서 `image="/hero/{이름}.jpg"` 로 넘긴다.

### 왜 화면마다 다른가

한때 **한 장을 모든 화면이 함께** 쓰게 두었다. 배너는 "여기가 어디인가" 만 말하는 자리이니
사진이 바뀔 이유가 없다고 봤는데, 그러자 스물넷이 전부 같은 공장 통로로 열려 **화면을 옮겨도
옮긴 것 같지가 않았다.** 지금은 화면마다 그 화면이 다루는 것을 찍은 사진을 쓴다.

없는 화면(약관 · 개인정보 처리방침 · 상세 화면들)은 `page.jpg` 가 기본으로 든다.

내려받은 주소는 이 모양이다:

```
https://images.pexels.com/photos/{ID}/pexels-photo-{ID}.jpeg?auto=compress&cs=tinysrgb&w=1920&h=640&fit=crop
```

`w=1920&h=640&fit=crop` 인 이유: 배너가 가로로 길쭉해서, 원본을 그대로 받으면 **위아래를
잘라 버릴 부분까지 내려받는** 일이 된다. 받을 때 잘라 오면 장당 50~400KB 로 준다. 화면 폭에
맞춰 다시 줄이는 일은 `next/image` 가 한다.

## 고를 때 걸렀던 것

**읽히는 상표.** `solutions/README.md` 에 적어 둔 것과 같은 기준이다 — 설비 제조사 이름이
기계에 작게 새겨진 정도는 넘어가지만, **사람이 입은 옷이나 쓴 장비, 간판에 붙은 것은 쓰지
않는다.** 있지도 않은 거래 관계를 그림 하나가 만들어 내기 때문이다.

## 바꾸려면

같은 이름으로 파일만 덮어쓰면 된다. 화면 쪽은 경로만 넘기므로 고칠 것이 없다. 대신 **위 표를
같이 고쳐야 한다** — 표와 파일이 어긋나면 다음 사람이 원본을 못 찾는다.
