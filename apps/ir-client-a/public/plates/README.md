# 솔루션 상세의 항목 사진

솔루션 여섯 화면(`app/solutions/*`)의 항목마다 위에 서는 사진이다. 쓰는 곳은
`app/solutions/_components/OfferingDetail.tsx` 의 `PLATES` 한 곳뿐이다.

## 어디서 왔고, 써도 되는가

전부 [Pexels](https://www.pexels.com/license/) 다. 그 라이선스는 **상업적 사용을 허용하고 출처
표기를 요구하지 않는다.** 그래도 적어 두는 이유는 나중에 "이 사진 어디서 났나" 를 물을 사람이
반드시 생기기 때문이다 — 그때 원본을 찾을 수 없으면 사진을 통째로 갈아야 한다.

원본 주소는 `https://www.pexels.com/photo/{ID}/` 이고, 내려받은 주소는 이 모양이다:

```
https://images.pexels.com/photos/{ID}/pexels-photo-{ID}.jpeg?auto=compress&cs=tinysrgb&w=1280&h=720&fit=crop
```

`w=1280&h=720&fit=crop` 을 붙이는 이유: 이 자리가 16:9 라 가로 사진을 그대로 받아 화면에서
자르면 **1280×720 만 보여 주려고 원본 몇 MB 를 내려받는** 일이 된다. 받을 때 잘라 오면 파일이
100~200KB 로 준다. 화면에서 다시 줄이는 일은 `next/image` 가 한다.

## 고를 때 걸렀던 것

**읽히는 상표.** `solutions/README.md` 에 적어 둔 것과 같은 기준이다 — 설비 제조사 이름이
기계에 작게 새겨진 정도는 넘어가지만, **사람이 입은 옷이나 쓴 장비, 간판에 붙은 것은 쓰지
않는다.** 있지도 않은 거래 관계를 그림 하나가 만들어 내기 때문이다.

이번에 그 기준으로 뺀 것:

## 바꾸려면

같은 이름으로 파일만 덮어쓰면 된다. 화면 쪽은 `PLATES` 의 경로를 읽으므로 고칠 것이 없다.
대신 **위 표를 같이 고쳐야 한다** — 표와 파일이 어긋나면 다음 사람이 원본을 못 찾는다.

항목이 넷을 넘는 절이 생기면 사진은 처음부터 다시 돈다(`% 길이`). 다섯째 항목에 첫째 사진이
다시 나오는 것이 보기 싫으면, 여기에 다섯째 장을 더하고 표에 한 줄 적으면 된다.
