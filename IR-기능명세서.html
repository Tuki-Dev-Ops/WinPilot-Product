8.3 데이터 관계 정의

후속 개발자가 데이터 모델을 설계할 수 있는 요구사항 수준으로 정의합니다. 물리 ERD 는 포함하지 않습니다.

순번관계정의
1문의 유형 : 문의하나의 문의 유형은 여러 문의를 가집니다. 유형은 정해진 목록(도입 · 견적 / 기술 지원 / 주주 · 투자자 / 기관 · 애널리스트 / 언론 / 기타)에서 선택합니다.
2지역 : 문의문의는 하나의 지역을 가집니다. 지역 목록은 정해진 행정구역 목록을 사용합니다.
3문의 : 처리 상태하나의 문의는 하나의 처리 상태를 가집니다. 상태 이력의 보관 여부는 별도 협의 대상입니다.
4문의 : 답변하나의 문의는 하나의 답변 본문을 가집니다. 답변 이력을 복수로 보관할지는 별도 협의 대상입니다.
5문의 : 첨부 파일하나의 문의는 여러 첨부 파일을 가질 수 있습니다. 파일 저장소 구축은 2단계 대상입니다.
6분류 : 공지사항공지는 하나의 분류(운영 · 서비스 · 약관)에 속합니다.
7공지사항 : 노출 상태하나의 공지는 노출 여부와 상단 고정 여부를 각각 가집니다. 두 값은 독립적으로 관리합니다.
8분류 : 뉴스소식은 하나의 분류에 속합니다.
9분류 : FAQFAQ 는 하나의 분류(도입 · 기술 · 지원)에 속합니다.
10제품 : 문제 · 해법제품 하나가 문제 정의와 해결 방식 한 벌을 가집니다. 사이트의 솔루션 상세 화면이 이 쌍을 읽습니다.
11제품 : 노출 순서제품은 사이트 메뉴에서의 노출 순서를 가집니다. 순서는 제품 설정 화면에서 관리합니다.
12서비스 : 노출 위치하나의 서비스는 홈 · 제품 목록 · 솔루션 상세 3개 위치에 노출됩니다. 위치별 문구가 달라지지 않도록 동일한 데이터를 조회합니다.
13연도 : 연혁연혁은 연도와 월을 가지며, 사이트에서는 연도 단위로 묶어 표시합니다.
14구분 : 특허 · 인증특허 · 인증은 하나의 구분에 속하며, 등록번호로 조회 가능해야 합니다.
15배너 · 팝업 : 노출 기간하나의 배너 또는 팝업은 노출 시작일과 종료일을 가집니다. 종료일이 없으면 상시 노출로 판정합니다.
16문구 : 국문 · 영문하나의 문구 키가 국문과 영문 한 쌍을 가집니다. 한쪽만 채워진 상태를 식별할 수 있어야 합니다.
17업태 : 업종공급자 정보의 업태 하나가 여러 업종을 가집니다. 업종은 선택한 업태에 속한 목록에서만 고릅니다.

8.8 예외 및 오류 응답 요구사항

순번상황발생 조건시스템 처리 · 화면 표시
존재하지 않는 데이터 조회요청한 식별자에 해당하는 데이터가 없습니다.서버는 404 로 응답합니다. 화면은 목록으로 돌아가는 경로와 함께 없는 대상임을 안내합니다.
미노출 데이터의 사이트 접근노출 상태가 아닌 데이터를 사이트 주소로 직접 요청했습니다.서버는 404 로 응답합니다. 데이터의 존재 여부를 드러내지 않습니다.
필수값 누락필수 항목이 비어 있는 상태로 저장을 요청했습니다.서버는 400 과 함께 누락 항목 목록을 응답합니다. 화면은 입력값을 유지한 채 항목별로 안내합니다.
형식 오류연락처 · 이메일 · 날짜 등 형식이 정해진 항목의 값이 규칙에 맞지 않습니다.서버는 400 과 함께 항목별 사유를 응답합니다. 미입력과 형식 오류를 구분합니다.
첨부 파일 오류허용되지 않은 확장자이거나 크기 상한을 넘었습니다.서버는 400 으로 응답하며 접수하지 않습니다. 화면은 사유를 구분해 안내합니다.
중복 데이터 등록이미 존재하는 값으로 등록을 요청했습니다. 특허 · 인증의 등록번호가 이에 해당합니다.서버는 409 로 응답합니다. 화면은 중복 항목을 지목하여 안내합니다.
허용되지 않은 상태값정의되지 않은 상태값으로의 변경을 요청했습니다.서버는 400 으로 응답하며 상태를 변경하지 않습니다.
권한 없는 접근인증되지 않았거나 등급이 부족한 요청입니다.미인증은 401, 등급 부족은 403 으로 구분하여 응답합니다. 인증 구현은 2단계 대상입니다.
검색 결과 없음조건에 해당하는 데이터가 없습니다.서버는 200 과 함께 빈 목록 및 총 건수 0 을 응답합니다. 오류로 처리하지 않습니다.
외부 서비스 오류지도 SDK 가 응답하지 않거나 인증 키가 유효하지 않습니다.화면은 빈 영역 대신 대체 안내를 표시합니다. 주소와 교통편 정보는 지도와 무관하게 제공되어야 합니다.
