회사 홈페이지 과업범위 정의서

구축 범위 · 2/4 2026년 8월 21일

1. 과 업 개 요

1.1 과업 목적

회사 홈페이지의 내용이 코드에 고정되어 있으면 공지 한 건, 제품 소개 한 줄을 고치는 데에도 개발과 배포가 필요하다. 그 결과 사이트는 구축 시점에 멈추고, 최신 소식과 특허 · 인증이 실제보다 뒤처진 상태로 남는다. 도입을 검토하는 방문자의 문의도 전화와 이메일로만 들어와, 누가 언제 무엇을 물었고 답했는지가 남지 않는다.

본 과업은 방문자가 이용하는 회사 사이트와 그 내용을 운영자가 직접 관리하는 서비스를 한 쌍으로 구축하여, 운영 주체가 개발 의존 없이 사이트를 현행으로 유지할 수 있도록 하는 것을 목적으로 한다.

두 서비스는 동일한 데이터를 참조한다. 데이터를 이중으로 관리하면 어느 쪽이 기준인지 확인할 방법이 없어지기 때문이다. 따라서 관리자의 변경은 사이트에 그대로 반영된다.

1.3 수행 단계

본 과업은 두 단계로 나누어 수행한다. Back-End 는 제외 범위가 아니라 2단계의 수행 범위이며, 1단계에서 확정한 요구사항이 그대로 2단계의 착수 명세가 된다.

단계수행 범위완료 기준
1단계기획 · UI 디자인 · Front-End 구현 · Back-End 요구사항 정의화면 63개가 정의대로 동작하고, Back-End 요구사항이 서버 개발에 착수할 수 있는 수준으로 확정된 상태.
2단계서버 애플리케이션 · 데이터베이스 · API · 인증 및 권한 · Front-End 연동정의한 규칙이 서버에서 지켜지는 상태.

1.4 전제 조건

  • 1단계 시점에는 서버와 데이터베이스가 없다. 화면이 참조하는 데이터는 공통 데이터 구조로 관리하며, 관리자의 변경은 브라우저 세션 범위에서 유지된다. 2단계에서 실제 서버로 대체한다.
  • 제품 · 서비스 소개 원고와 회사 정보는 발주처가 제공한다. 본 과업은 제공된 콘텐츠를 화면에 반영하는 범위까지 수행한다.
  • 제품과 서비스는 화면 구조가 코드에 있어 문구만 관리한다. 제품을 늘리는 것은 별도 협의 대상이다.
  • 오시는 길 화면은 카카오 지도를 사용한다. 키 발급과 도메인 등록은 발주처 계정으로 수행해야 하며, 상세 준비 사항은 「요구사항 정의서」에 있다.

2. 과 업 범 위

어디까지 만드는가 — 화면 단위로 확정된 범위다. 이 표에 없는 화면은 범위 밖이다. 각 화면이 무엇을 하는가는 「기능 명세서」의 같은 기능 ID 항목에 있다.

2.2 회사 사이트 화면 목록

1HOME-001메인 페이지메인서비스의 진입 화면으로, 어떤 회사이며 무엇을 제공하는지를 한 화면에서 제시한다. 회사 소개 · 서비스 · 제품 · 소식 네 영역의 요약을 배치하여 방문자를 각 하위 화면으로 분기하는 진입점 역할을 수행한다.
2COMPANY-001회사 소개ABOUT회사가 지향하는 바, 수행하는 업무, 제공하는 제품을 순서대로 전달하는 회사 소개 화면이다. 연혁 나열이 아니라 현재 무엇을 하는 회사인지를 중심으로 구성하여, 방문자가 거래 상대로서 회사를 판단할 수 있는 근거를 제공한다.
3HISTORY-001연혁ABOUT회사의 주요 이력을 연도 단위로 제공하는 화면이다. 개별 항목을 나열하지 않고 연도로 묶어 배치하여, 어느 시기에 어떤 변화가 있었는지를 확인할 수 있도록 한다.
4CERT-001특허 및 인증ABOUT보유한 특허와 인증을 조회하는 화면이다. 방문자가 제시받은 등록번호가 실제 이 회사의 것인지 확인할 수 있도록 검색과 분류를 제공하는 것을 목적으로 한다.
5CERT-002특허 · 인증 상세ABOUT특허 또는 인증 한 건의 상세 정보를 제공하는 화면이다. 개별 항목에 고유 주소를 부여하여 해당 건을 그대로 지목하고 공유할 수 있도록 한다.

1ADMIN-001대시보드대시보드운영자가 문의 접수 현황을 기간 단위로 확인하는 운영 현황 화면이다. 유입량과 유입 경로 두 가지를 우선 제시하고, 지표 선택 시 해당 조건이 적용된 관리 화면으로 연결한다.
2INQUIRY-002문의 목록문의사이트 문의 양식으로 접수된 건을 조회하고 처리 현황을 관리하는 목록 화면이다. 미응답 건을 우선 식별할 수 있도록 검색과 상태 필터를 제공한다.

16PRODUCT-004제품 설정제품사이트 제품 메뉴의 구성과 노출 순서를 관리하는 화면이다. 여기서 정한 순서가 사이트 상단 메뉴와 제품 목록의 배치 순서가 된다.
17SOLUTION-007문제 · 해법 목록문제 · 해법제품별 문제 정의와 해결 방식이 작성되었는지 조회하는 목록 화면이다. 사이트의 솔루션 상세 화면이 참조하는 값의 작성 현황을 확인한다.
18SOLUTION-008문제 · 해법 상세문제 · 해법문제 정의와 해결 방식의 문구를 수정하는 상세 관리 화면이다. 제품 상세 관리 화면과 동일한 입력 구성을 사용한다.
19SOLUTION-009홈 무대 차례문제 · 해법홈 화면 서비스 영역에 배치되는 여섯 항목의 순서를 확인하는 화면이다. 조회 전용이며, 각 항목이 연결하는 주소를 함께 확인할 수 있다.
20SERVICE-001서비스 목록서비스인력이 현장에서 수행하는 서비스 항목의 소개 문구가 작성되었는지 조회하는 목록 화면이다.
21SERVICE-002서비스 상세서비스서비스 소개 문구를 수정하는 상세 관리 화면이다. 제품 상세 관리 화면과 동일한 입력 구성을 사용한다.
22SERVICE-003서비스 설정서비스서비스 항목이 사이트의 어느 위치에 어떤 문구로 노출되는지를 한 화면에서 확인하는 화면이다. 동일한 서비스가 여러 위치에 서로 다른 문구로 노출되는 상황을 점검하기 위한 것이다.

24HISTORY-002연혁 목록회사사이트 연혁에 노출되는 항목을 조회하고 관리하는 목록 화면이다.
25HISTORY-003연혁 등록회사사이트 연혁에 노출할 항목을 신규 등록하는 화면이다.
26HISTORY-004연혁 상세회사등록된 연혁 항목을 수정하는 상세 관리 화면이다.
27CERT-003특허 및 인증 목록회사보유한 특허와 인증을 조회하고 관리하는 목록 화면이다. 등록번호로 조회할 수 있어야 하므로 번호 기반 검색을 제공한다.
28CERT-004특허 및 인증 등록회사취득한 특허 또는 인증을 사이트에 게시하기 위해 신규 등록하는 화면이다.
29CERT-005특허 및 인증 상세회사등록된 특허 또는 인증을 수정하는 상세 관리 화면이다.

31BANNER-002메인 비주얼 등록배너홈 상단에 게시할 메인 비주얼을 신규 등록하는 화면이다. 노출 상태와 기간을 분리하여 관리함으로써 사전 등록과 예약 게시를 지원한다.
32BANNER-003메인 비주얼 상세배너등록된 메인 비주얼의 문구와 노출 기간을 수정하는 상세 관리 화면이다.

35BANNER-006팝업 상세배너게시 중인 팝업의 문구와 노출 기간을 수정하는 상세 관리 화면이다.

42LEGAL-004개인정보 처리방침설정사이트 하단의 개인정보 처리방침 링크가 여는 본문을 작성하고 게시하는 화면이다. 작성과 게시를 분리하여 관리한다.

3. 제 외 범 위

아래는 본 과업에 포함하지 않는다. 적어 두지 않으면 포함된 것으로 읽히므로 따로 둔다. 「사유」를 함께 적는 것은 빠진 항목을 볼 때마다 왜 빠졌는지 되묻는 일을 없애기 위해서다.

순번구분항목사유
1BX로고 · BI 가이드 제작로고는 원본 파일을 제공받아 사용한다. 눈으로 보고 다시 그린 로고는 그 브랜드의 표장이 아니다.
2패키지 · 인쇄물 · 편집 디자인본 과업은 웹 화면에 한정한다.
3제품 · 모델 촬영 · 영상 제작이미지와 영상은 발주처가 제공한다.
4기획시장 조사 · 경쟁사 분석발주처가 제공하는 브랜드 기준을 따른다.
5UI 디자인시안 파일 (PSD · AI)디자인은 실제로 동작하는 화면으로 인도한다. 별도 시안 파일은 만들지 않는다.
6기능제품 · 서비스 신규 등록 및 삭제화면 구조가 코드에 있어 문구만 관리한다. 제품을 늘리는 것은 별도 협의 대상이다.
7관리자 계정 · 권한 관리 화면현재 범위에 없다. 계정 발급과 권한 회수 절차의 정의가 필요하다.
8사이트 회원 체계방문자는 로그인 없이 전 화면을 이용한다. 로그인은 관리자에만 둔다.
9방문 통계 수집조회 화면만 제공한다. 수집 방식과 보존 기간은 2단계에서 확정한다.
10결제 · 예약 · 외부 시스템 연동정의하지 않는다. 지도는 화면에서 지도 SDK 를 직접 호출한다.
11운영클라우드 계정 · 도메인 · 인증서구매와 요금은 발주처가 부담한다. 구성 지원은 수행한다.
12CI 및 CD 파이프라인 운영구축 지원 범위 밖이다.
13취약점 진단 · 보안 점검포함하지 않는다. 비기능 명세서의 보안 요건은 점검이 아니라 설계 기준이다.
14콘텐츠 제작 · 등록 대행원고와 이미지는 발주처가 제공하며, 등록은 관리자에서 직접 수행한다.
15서비스 운영 대행 · 정기 유지보수인수 이후의 운영은 별도 계약으로 정한다.
